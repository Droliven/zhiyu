## 旧材料如何合并

- 原Visual/Geometry Action与潜在动作精读并入动作专题的论证；原ICL专题、相关周报条目并入上下文学习专题。
- 原R1/GRPO、几何一致视频和物理生成精读，按“奖励优化”和“生成机制”拆分整合，避免把监督对齐误归RL；物理约束、实例动力学与独立评价进一步组织为“物理合理性”独立专题。
- 三份因果综述统一进入因果与可靠性专题，保留因果识别、时间因果与反事实编辑之间的区别。
- 原HOI、交互世界模型、手部重建精读，集中进入“手物交互重建与生成”，与通用重建专题交叉引用；原WAM、Dyna-2等作为生成式世界模型总览来源；JEPA与隐式状态表征、流式视频各保留独立专题。
- 原“从可预测到可执行”及各周报中的跨主题内容，按上述研究问题拆入相应专题。代码Agent相关新卡片形成独立专题。

## 维护

`catalog.json`列出新专题、保护条目和归档条目。修改新专题后运行：

```sh
python3 scripts/ingest_reports.py --catalog-only
python3 scripts/validate_data.py
python3 scripts/check_asset_budget.py
```

`--catalog-only`只重建报告目录和引用关联，不改论文数据；普通完整导入同样应用专题目录。正文使用现有网页支持的内联链接、表格、目录和本地相对图片。新增论证应引用主来源，摘要层证据不能升级为已核验的定量结论。
