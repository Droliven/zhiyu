# Looped Transformer 专题：用循环计算深度解耦参数规模与推理能力

**更新日期**：2026-11-28

**报告标签**：预训练与扩展律, 世界模型, 3D/4D, 扩散与流匹配, 表征学习与潜空间

> 传统 Transformer 将“物理参数量（记忆容量）”与“前向计算深度（推理步数）”死死绑在一起：想让模型多想一步，就必须多堆一层独立权重。2026 年底，从 750B 旗舰语言模型（**GLM-5.4**）、0.5B 免标定 4D 感知底座（**π⁴**）、1.3B 具身 4D 世界模型（**Loop4D**）到追求极限压缩的循环世界模型/通用循环框架（**General Looped Model / LoopWM**），四个截然不同的赛道几乎同时转向 **Looped Transformer**。本专题拆解其统一数学机制、横向比较四条路线的工程取舍，并提炼可直接迁移到具身智能与世界模型架构设计中的实操判断。

## 一、为什么是现在？Looped Transformer 的本质机制与三块新拼图

在标准 $L$ 层 Transformer 中，隐状态依次穿过 $L$ 组互不共享的权重：$h_l = f_{\theta_l}(h_{l-1})$。这种设计把两种本质不同的能力需求混为一谈：

1. **静态容量（记忆与先验库）**：能存下多少事实知识、视觉纹理与跨场景先验，主要受限于**物理参数量**与显存容量；
2. **动态深度（多步推理与状态精炼）**：能完成多少跳因果推演、跨视角几何消歧或物理动力学精炼，主要受限于**前向有效计算深度**。

**Looped Transformer**（循环深度 / Recurrent Depth）做的是一次干净的解耦——将网络收束为经典的三段式“三明治”结构：**Prelude（前端映射）→ Looped Core（权重共享循环核）→ Coda（末端解码）**。中段同一组参数 $\theta_{\text{core}}$ 在一次前向传播中被重复调用 $K$ 次：

$$h^{(0)} = \text{Prelude}(x), \qquad h^{(k)} = \mathcal{U}\!\left(h^{(k-1)},\, f_{\theta_{\text{core}}}\!\left(h^{(k-1)}, e_k\right)\right),\quad k = 1,\dots,K, \qquad y = \text{Coda}(h^{(K)})$$

其中 $e_k$ 是**循环步进条件（Step Conditioning）**，$\mathcal{U}$ 是**状态更新规则**（残差、逐 Token 门控或分模态自适应门控）。

### 为什么 2018 年就有的概念，直到 2026 年才集中落地？

早年 Universal Transformer 等权重共享模型始终难以进入主流，卡在三个具体的工程死结；而 2026 年这四篇工作正好各自补齐了对应的关键拼图：

- **死结 1：跨轮分布漂移与激活爆炸** → 如今靠**显式步进条件 $\tau$**（π⁴）、**逐 Token 渐进门控**（GLM-5.4）、**谱稳定性约束**（LoopWM）与**局部非退化 + 分模态门控**（Loop4D）把循环变成稳定收敛的动力系统。
- **死结 2：从头训循环在等算力下吃亏** → GLM-5.4 给出极度务实的破局：**先非共享预训练吃满知识记忆，再低成本（~10% 额外算力）继续训练把中段改造成循环**；而在结构化 4D 几何/动力学解码器（π⁴、Loop4D）中，加了步进条件即可从头稳定收敛并在后期反超非循环基线。
- **死结 3：长上下文 KV 缓存按轮数翻倍** → GLM-5.4 用**重叠式混合 KV 缓存**（二轮复用一轮全局稀疏 KV + 128 Token 局部滑窗）与**稀疏索引复用**，守住了 1M 上下文的部署底线。

## 三、深度拆解：四个赛道如何用循环解决完全不同的瓶颈

读懂 Looped Transformer 的关键，是看清**每个团队拿“权重共享省下来的显存/参数预算”换了什么，以及他们如何驯服循环的副作用**：

### 1. GLM-5.4：预训练改造 + 门控涌现的“软自适应计算”

大语言模型既要海量知识（吃参数），又要深层逻辑（吃深度）。GLM-5.4 证明了最稳妥的工业路径不是从零训循环，而是**先非共享预训练攒知识，再中段循环改造提深度**。

最值得深究的机制是其**逐 Token 门控的自发分工**：即便架构上是固定的 2 轮循环，训练后 Pass 1 会自动收敛为小门控（保守收集全局上下文、稳住分布），Pass 2 打开门控写入完整精炼结果；且面对困难推理 Token 时，Pass 1 会主动加大写入幅度。这相当于**在保持 GPU 规整批处理的前提下，实现了“软自适应计算”**。其直接结果是“思考内化”——AIME25 暴涨 11.25 分的同时，显式输出长度反降 2%–14.9%。

### 2. π⁴：把参数砍半，换取 64 视角超长上下文与单次前向防 OOM

在 3D/4D 重建领域，真正的敌人不是参数太少，而是**多视角注意力在长序列下的显存爆炸**。π⁴ 的高明之处在于，它没有把 0.5B 轻量架构当成噱头，而是把省下的显存全部投入训练 **64 视角联合上下文**（竞品普遍只能训十几帧）。

消融表明，**显式循环步进条件 $\tau$** 是让循环解码器在训练后期反超非循环基线的决定性开关（相机位姿损失降 10.2%）；再叠加“冻结度量几何 + Spatial AdaLN 注入 + 2D 对应解析抬升”，最终让一个 0.5B 模型在 361–800 帧大场景上把 1.3B+ 竞品全线打到 OOM。

### 3. Loop4D：双流扩散里的局部非退化与分模态校准

在具身 4D 世界模型里，RGB 纹理与 3D 坐标的数值尺度、动态频率完全不同，且机械臂末端只占画面极小面积。Loop4D 揭示了两个极具普适性的教训：

- **前端表征决定上限**：VAE 静态重构 PSNR 变高（37.38→37.86）反而让生成 FVD 恶化（588.7→697.5），说明世界模型必须先用预测性重构保住运动信息；
- **多模态循环必须分模态调步长 + 保护关键区域**：共享权重可以，但必须靠**机械臂区域非退化约束**防止背景梯度把机械臂磨糊，靠**轻量分模态门控**分别调节 RGB 与 XYZ 的更新幅度。

### 4. General Looped Model / LoopWM：延迟解码与极限压缩的双刃剑

FaceMind 的 *LoopWM*（`2606.18208`）贡献了三件非常有价值的算法武器：**谱稳定性约束**、**按难度早停（ACT）**，以及最值得世界模型领域借鉴的**延迟解码（Deferred Decoding）**——连续 $K$ 步纯潜空间推演、仅在终点解码，直击多步 rollout 的解码误差滚雪球。

但面对撤回稿中流传的“94M 打败 5B、显存省 98%”，必须守住两条科学底线：第一，**静态权重显存压缩 ≠ 推理 FLOPs 或延迟同步缩减**，多轮串行循环依然要付算力与时延账；第二，LoopWM 的 100× 参数效率验证于离散文本世界（ScienceWorld/AlfWorld），迁移到高维连续视觉物理世界与知识密集型任务时，物理参数量依然存在硬记忆上限。

## 四、选型决策矩阵与尚未解决的共性瓶颈

如果你想在自己的模型或具身系统中引入 Looped Transformer，可直接按以下四条工程准则决策：

1. **知识密集型底座（LLM / VLA）→ 走 GLM-5.4 路线（预训练改造 + 逐 Token 门控 + 混合缓存）**；切忌在缺少千卡级消融验证时盲目从零预训练纯循环大模型。
2. **结构化几何/动力学解码器（4D 感知 / 世界模型）→ 走 π⁴ & Loop4D 路线（步进条件 $\tau$ + 分模态门控 + 局部非退化约束）**，把省下的显存优先拿去拉长历史视角上下文或塞进显式 3D 几何流。
3. **长程想象规划（世界模型 rollout）→ 借鉴 LoopWM 的 Deferred Decoding**，尽量把多步推演留在潜空间内完成，减少每步显式解码带来的误差放大与延迟。
4. **高频真机闭环（10–50 Hz）→ 严守“参数效率 ≠ 延迟效率”红线**：循环 $K$ 轮意味着串行深度乘以 $K$，实时控制中必须将循环轮数控制在极小值（如 2–4 轮）或配合异步快慢双系统，否则推理滞后会直接抵消精度收益。

**仍未彻底解决的两大共性难题**：一是如何在 GPU 大 batch 推理下实现真正省 FLOPs 的**动态硬早停**（目前 GLM-5.4 的逐 Token 门控只是不省 FLOPs 的软自适应）；二是隐式循环深度与显式 CoT / 扩散步数叠加时的**算力预算失控风险**（如 GLM-5.4 偶发的“马拉松思考”）。

## 五、面向具身智能的架构合流图景

把这四篇工作放回具身智能的系统栈里，已经能清晰看到下一代轻量、长程 4D 具身系统的三段拼图：

- **感知层（π⁴ 范式）**：0.5B 循环 4D 解码器换取超长多视角上下文，免标定输出度量几何与表面贴合轨迹；
- **推演层（Loop4D + LoopWM 范式）**：前端用保运动 4D VAE，后端用带分模态门控的双流 LoopDiT 与潜空间延迟解码，在 1B 级参数内完成长程 4D 想象；
- **决策层（GLM-5.4 范式）**：在成熟 VLA 底座中段做低成本门控循环改造，把多步空间规划与反事实推断内化进隐式深度，压缩显式推理耗时。
