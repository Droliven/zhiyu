# 物理知识如何进入机器人：从空间感知、动作监督到世界仿真

**更新日期**：2026-11-11

**报告标签**：世界模型, 机器人学习, 跨本体迁移, 预训练与扩展律, 数据与评测

> 围绕六篇工作，区分恢复场景、定位操作目标、塑造策略特征、标注动作阶段、联合生成动作和模拟动作后果。重点不是模型统一了多少任务，而是新增的信息通过什么接口影响控制，以及哪种证据足以证明这个接口有用。

## 先看信息缺在哪里

“把杯子放进抽屉”至少涉及四件事：识别杯子与抽屉、判断可达位置和空间关系、组织开抽屉与搬运的先后、执行动作并判断结果。一次失败可能出在其中任何一处。给模型增加更多任务标签，不一定提供了缺失的几何；把视频生成得更清楚，也不一定让它更听从动作。

这六篇工作的共同价值，是为这些缺口提供不同形式的结构信息。它们不能排成一条性能榜，也不构成已验证的装配流水线。

| 工作 | 交给模型的关键结构 | 推理时真正得到什么 | 最直接的证据 |
| --- | --- | --- | --- |
| Foundation4D | 多相机、多时刻共享的几何与语义 | 深度、检测、占据、可渲染场景 | 感知/重建指标与多任务消融 |
| GroundingPI | 与语言对应的点、框等视觉基元 | 精确 grounding；接动作模块后执行控制 | 感知基准与下游示范效率 |
| SLA | 冻结三维教师的空间特征 | 原 VLA 的动作输出 | 预训练/下游空间对齐的受控比较 |
| RoboAtom | 技能类别、描述和时间边界 | 自动分段标注；分层系统的控制动作 | 时间定位与下游控制 |
| UniWAM | 语言、未来视觉与连续动作共同监督 | 联合语义、未来视频与动作预测 | 泛化、指令跟随及组件消融 |
| PrimeSim | 与每帧对应的动作、多视角和自生成历史 | 给定动作后的未来视觉观测 | 动作响应、策略排序和模型内 RL |

## 空间基础有两种进入策略的方式

Foundation4D 先处理“场景是什么”。它从多摄像头驾驶视频同时恢复几何、目标、语义占据和 Gaussian 场景，通过空间、相机、时间分解注意力共享信息。检测与重建不必各自重复学习所有空间结构：其消融中，几何和占据加入后，检测 Top-mAP 从 40.94 升至 42.14；但占据任务加入更多目标后也可能退步。因此，共享表示的价值需要按任务验证，不能用“统一”直接替代互益证据。[原文](https://arxiv.org/html/2610.30340v1)。

它提供了理解动态场景的一种基础，却没有回答“给定一个新动作会发生什么”：时间变化的重建和动作条件动力学不同。论文也主要面向自动驾驶感知与离线重建，部分评测使用未来帧，不能把榜单成绩直接外推为机器人在线控制能力。

GroundingPI 和 SLA 则直接把空间知识送向动作学习，但监督来源不同。**GroundingPI 通过点框坐标 token 监督预训练感知骨干，控制时向动作模块传递骨干中间特征；SLA 用三维教师对齐已有 VLA 的中间视觉特征。** 两者最终都需要特征被策略有效利用，SLA 的三维教师和辅助对齐分支只在训练时运行。[GroundingPI](https://arxiv.org/html/2609.39601v2)、[SLA](https://arxiv.org/html/2611.08373v1)。

两种证据也应分别解读。GroundingPI 在 RoboCasa-GR1 用 50% 示范取得 28.75% 成功率，超过最强对比骨干用 75% 示范的 27.75%，支持“感知预训练提高所测设置的动作数据效率”。SLA 在相同完整数据下，RoboTwin Clean2Random 仅下游空间对齐为 57.1%，预训练和下游都对齐为 72.3%，更直接说明空间监督出现的阶段很重要。

坐标监督与教师特征监督保留的信息不同，比较时应追问任务所需信息是否留下、策略是否学会使用。点框标签强调目标定位，却未必约束接触姿态；三维教师提供更丰富的几何特征，也不保证这些几何都被准确吸收。评估这两条路线，应该固定动作头、数据与预算，再检验对小物体、遮挡、相机变化和示范量的影响。

## 长任务还缺少“何时做哪一步”的监督

即使杯子和抽屉的位置都已知，一条任务指令仍未标出开抽屉、抓杯、搬运、放置的边界。RoboAtom 补的是这一层：给已有示范增加统一的技能类别、对象相关描述和时间区间，让不同数据源的中间步骤可以共同学习。

它的规模化手段不是要求通用 VLM 独立读懂所有瞬时接触，而是先人工核对种子，再用 PhysExtend 根据夹爪和运动线索，在动作顺序相同的重复执行中传播边界。约 145 万轨迹、688 万片段和 29 类技能说明这是一套监督资源工程；“相同动作顺序”则限定了传播适用范围。[原文](https://arxiv.org/html/2610.40207v1)。

原子动作条件加分层执行，使 LIBERO-Long 从 95.0% 升至 98.2%。这个结果支持细粒度监督与调度的组合用途，却不能单独量出标签的贡献，因为系统同时改变了上层调度。若要证明“可重用技能”而不只是更容易跟随标注，应进一步固定执行器，测试未见步骤组合、边界误差与切换失败后的恢复。

**空间监督和时间监督解决的是互补缺口。** 前者帮助策略分清目标与几何关系，后者帮助把目标拆成阶段。二者都有价值，但这批论文没有联合证明它们相加必然提升；组合是否有效，还取决于标注粒度、坐标接口和控制器能否消费这些信息。

## 从联合策略到仿真器，输出方向发生了变化

UniWAM 把语义理解、未来视频与动作专家接入联合注意力，希望动作既读懂目标，又利用视觉动态先验。其关键训练接口是物理语言：把末端运动写成自然语言，使人类和机器人数据具有共同的运动描述；再按数据可用监督训练相应分支。

联合预测还带来新的依赖。若动作在训练中过度读取接近真值的未来视觉，推理时较差的预测就会拖累控制。因此 UniWAM 后训练主动扰动未来视觉特征，并用历史动作初始化 flow matching，以较少去噪步骤维持控制质量。LIBERO-Plus 92.6% 和四项真机指令任务平均成功率 67.5% 支持这套方案的策略用途，而不是长期物理推演已经可靠。[原文](https://arxiv.org/html/2610.02054v4)。

人类数据也并非无条件有益：在论文考察的小规模区间，混入人类数据可能降低性能，规模增加后才表现出收益。这提醒我们，跨本体扩展还涉及动作语义与分布匹配，不能把不同论文的小时数接成一条普遍扩展律。

PrimeSim 的接口反过来：**动作由外部策略提供，模型负责生成后续观察。** 它用 31 维动作布局统一跨本体数据，通过逐帧注意力和残差注入建立动作—帧对应；少步因果生成、自 rollout 训练及分层记忆则处理运行速度和自生成历史漂移。它必须让环境回应实际生成的运动，仅生成“像示范”的视频不够。[原文](https://arxiv.org/html/2611.04870v1)。

最有分量的证据因而是策略效用：8 个 OpenVLA-OFT 策略各在同 300 个 LIBERO-Spatial 初态执行，PrimeSim 与参考物理仿真器的汇总成功率相关性为 r=0.99，平均绝对差 2.8 个百分点；再在 PrimeSim 内做 200 步 GRPO，返回物理仿真器的成功率从 61.7% 升至 73.2%。这比单独的像素指标更接近“仿真器是否可用”，但仍限于仿真迁移，未证明真机训练可被替代。

## 哪些结论已经成立，哪些仍需下一层证据

| 已有证据 | 支持的判断 | 还不能替代的检验 |
| --- | --- | --- |
| 感知/几何消融改善 | 新监督改变了可用表示 | 相同控制器下能否利用它 |
| 示范效率与 OOD 成功率改善 | 表示或训练方案有下游价值 | 哪个组件造成收益、是否跨平台稳定 |
| 联合视频动作表现改善 | 联合训练方案有策略价值 | 视频监督的独立作用，以及动作扰动下的响应是否准确 |
| 仿真器中的策略排序一致 | 对该策略族有评价价值 | 单任务失败、奖励误判和陌生策略分布 |
| 模型内 RL 迁回物理仿真 | 生成环境支持有限策略优化 | 长预算利用模型误差，以及真机迁移 |

这些工作提示一种更具体的研究取向：先确认失败缺的是定位、几何、阶段还是动作后果，再选择监督与接口；随后沿“表示→控制→交互”逐层验证。PrimeSim 的最高质量结果使用 50 步采样，10.1 FPS 来自四步短窗配置，约 105 秒是另一组长程实验的模拟时长。把这些拆开，才能判断实际部署是否满足同一组要求。

建议先读 GroundingPI 与 SLA，理解空间知识如何影响策略；接着读 RoboAtom 看时间结构；再读 UniWAM 与 PrimeSim 区分“产生动作”和“模拟动作”。Foundation4D 适合作为几何、语义与重建共享表示的对照，而不是把自动驾驶感知模型直接当作操作策略。
