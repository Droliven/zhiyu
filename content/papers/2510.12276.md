## 当前挑战

主流 VLA 建立在纯 2D 图文预训练的 VLM 之上——作者的深度线性探针（Fig. 3）表明，原始 VLA 的视觉嵌入几乎恢复不出有效的 3D 空间结构。现有显式 3D VLA 方案各有瓶颈：

- **外挂深度/点云传感器难以规模化**：真机深度噪声大、相机标定与传感器形态各异，且大量开源机器人数据集不含深度，严重制约数据扩展。
- **推理期串联深度估计器易受上限拖累**：先用单目深度模型估 3D 再喂给策略，不仅增加推理延迟，还会把深度估计误差直接传给动作头。

## 研究动机

**核心思路：不改 VLA 架构、不加 3D 传感器输入，只在训练期把 VLA 中间层的视觉 Token 隐式对齐到冻结 3D 基础模型（VGGT）的空间表征，让策略自己“长出” 3D 空间感，部署零额外开销。**

由于自回归/流匹配动作 Token 直接以 VLM 视觉 Token 为条件，只要在训练期通过轻量余弦对齐损失牵引中间视觉表征，就能在不破坏原 VLM 语义和推理架构的前提下注入多视角一致的 3D 几何知识。这一范式也是后续 [SLA](../../index.html#paper=arxiv-2611-08373)（将其扩展至持续预训练）的直接奠基工作。

## 技术方案

**输入**：多视角 RGB 图像、语言指令与本体状态（推理期完全不需要深度图、点云或相机标定）。

**过程**：训练期将同一组多视角 RGB 同时送入 VLA 与冻结的 VGGT，用带位置编码的 VGGT 特征作为空间目标，通过 BN + 两层 MLP 投影 VLA 较深中间层的视觉 Token，联合优化动作损失与逐像素余弦对齐损失 $\mathcal{L}_{\text{SF}}=\mathcal{L}_{\text{action}}+\alpha\mathcal{L}_{\text{align}}$。

**输出**：标准 VLA 连续或离散动作；VGGT 教师与对齐投影器在推理期全部丢弃，推理架构与延迟与原 VLA 完全一致。

核心设计拆解（[方法：第 2 节](https://arxiv.org/html/2510.12276v2#S2)）：

- **VGGT 多视角几何教师 + 位置编码**：相比 2D 语义教师（SigLIP / DINOv2），VGGT 输出多视角一致的 3D 几何表征；在目标特征上叠加位置编码（PE）能显著保住自回归序列的相对空间顺序（LIBERO-Long 消融从 84.4% 跳升至 **94.2%**）。
- **对齐层选择“较深但不最深”**：以 32 层 OpenVLA-OFT 为例，对齐第 24 层（平均 96.9%）优于浅层（第 1 层 94.6%、第 16 层 93.8%）和末层（第 32 层 94.8%）——太浅会导致深层丢失空间信息，太深则视觉特征已坍缩进模态无关空间。
- **训练与数据双高效**：外部 3D 教师提供低偏差的通用几何先验，既加快收敛速度，又大幅降低小样本过拟合。

## 实验结果

| 评测基准 | Spatial Forcing 表现 | 核心对比与设置 |
| --- | --- | --- |
| **LIBERO**（4 套件，基于 OpenVLA-OFT） | 平均 **98.5%**（Spatial 99.4 / Object 99.6 / Goal 98.8 / Long 96.0） | 无需 3D 输入超越 OpenVLA-OFT（97.1%）、$\pi_0$（94.2%）及显式 3D VLA（GeoVLA 97.7%、3D-CAVLA 98.1%） |
| **RoboTwin 2.0**（基于 $\pi_0$ + LoRA） | Easy 与 Hard 全面领先基线 $\pi_0$ | 域随机化 Hard 任务提升尤为明显，减少对背景/光照捷径的依赖 |
| **训练与数据效率**（LIBERO，Table 2） | 同精度训练提速 **3.8×**；仅 5% 数据达 **75.8%** | 同数据量高出 25.8%，达同成功率数据效率提升 **5.9×** |
| **真机 4 任务**（AgileX Piper，40 单臂 / 20 双臂示范） | 透明杯叠放较基线 **+47.5 pp**；绿块变高度放置 **85%** | 涵盖光照变化、目标变化、高度变化与双臂端锅水平平衡 |

**组件消融（Table 2，单卡 H100）**：基线 92.7% → SigLIP 94.0% → DINOv2 94.1% → VGGT 无 PE 94.7% → **VGGT + PE（第 24 层）96.9%**，证实了“3D 几何教师 + 位置编码 + 较深中间层”三者缺一不可。[实验：第 3–4 节](https://arxiv.org/html/2510.12276v2#S3)。

## 总结讨论

Spatial Forcing 用极简的训练期余弦对齐（零推理开销）开创了**“隐式 3D VLA”**这条高性价比路线：证明了不用把噪声深度图或点云硬塞进 VLA 输入，单靠 3D 基础模型教师的中间层表征牵引，就能同时赢过 2D VLA 与部分显式 3D VLA，并带来数倍的收敛与样本效率红利。

它的局限也直接催生了后续的 **[SLA](../../index.html#paper=arxiv-2611-08373)**：Spatial Forcing 仅在**下游后训练**施加对齐，且需**手动挑选单一固定对齐层**（如第 24 层），在跨场景、跨高度与跨本体泛化时仍有明显天花板——SLA 正是把这一机制前移到大规模持续预训练，并用多层自适应门控与状态 Dropout 补齐了短板。

## 局限、失败案例与开放问题

- **仅限下游后训练，跨场景可迁移性有限**：空间能力停留在任务特化微调阶段，未在多本体预训练中形成通用空间底座（后续 SLA 的真机 F/H 条件消融亦印证了这一点）。
- **需手工挑选固定对齐层**：不同 VLM 主干与任务域的最佳对齐深度不同，缺乏自适应多层聚合机制。
- **未利用部分数据自带的深度/标定**：VGGT 教师仅吃纯 RGB，无法像后续 OmniVGGT 那样吸收数据集中已有的相机标定或深度真值。
- **表征对齐不等于物理动力学**：提升的是静态/几何空间感知，不涉及动作条件未来演化与接触力建模。
