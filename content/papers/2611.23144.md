## 当前挑战

要把单图、无序多图和长视频的 4D 感知（几何、位姿、尺度、3D 跟踪与运动分割）统一进一个免标定前馈模型，现有工作卡在三个实际矛盾上：

- **直接回归 3D 轨迹容易“飘离表面”**：像 ARROW 那样直接预测参考系下的 3D 端点，会把对应关系、目标深度、相机位姿和场景尺度搅在一起——相机一走远，轨迹就会偏离重建出的场景表面；而像 MoSE3 那样另预测一套跟踪深度，也会和重建几何打架。
- **模型太重，长序列推理易爆显存**：主流 3D/4D 模型普遍在 1B–1.7B 参数量级，训练只能看十几帧，遇到几百到上千帧的大场景单次前向很容易 OOM 或严重漂移。
- **野外动态视频缺几何真值**：互联网动态视频没有深度和外参，直接拿传统重建方法生成伪标签又会被移动前景带偏。

## 研究动机

**核心思路：几何与运动解耦——先建好轻量、长上下文的度量几何底座，再让运动分支只管“2D 找对应”，最后用重建几何把 2D 点直接抬升到 3D。**

这个设计靠三条彼此咬合的取舍落地，最终把整套系统压到了 **~0.5B 参数**（不到多数基线的一半）：

- **2D 预测 + 3D 解析抬升，消灭轨迹漂移**：冻结几何分支，运动分支只在尺度无关的 2D 图像空间预测稠密像素对应，再用目标帧重建好的度量点图直接采样得到 3D 轨迹。只要目标点可见，轨迹从构造上就严格贴合重建表面。
- **循环权重共享，省出显存看更长上下文**：两个解码器都采用循环 Transformer（同一对注意力块迭代执行），把省下的参数和显存直接用来训练单场景 **64 视角**联合上下文，使模型推理期能单次前向撑起数百乃至上千帧。
- **补齐动态与广角数据短板**：结合大场景合成渲染（抗偏置焦距/滚转增强）、“抹掉动态前景+视频修复”后的互联网背景几何伪标签，以及游戏引擎原生动态轨迹（GameRealm）。

## 技术方案

**输入**：任意数量的未标定 RGB 图像（单图、无序多图或视频，无需时间顺序）；跟踪任务额外指定查询视角。

**过程**：共享 DINOv3 编码后，先由无参考帧循环几何解码器联合稀疏 3D 细化恢复每帧度量点图与相机位姿；再冻结几何，将其特征通过 Spatial AdaLN 注入循环运动解码器，预测 2D 稠密对应与运动掩码，并将 2D 对应直接采样抬升到目标帧度量 3D 表面。

**输出**：单次前向统一输出每帧度量 3D 点图、相机外参、全局度量尺度与几何置信度，以及多图下的 2D/3D 点轨迹、可见性与运动物体掩码。

核心设计拆解（[方法：第 3 节](https://arxiv.org/html/2611.23144v1#S3)）：

- **无参考帧循环几何底座（343M）**：沿用 $\pi^3$ 的对称建模，不指定参考帧，打乱输入顺序只打乱输出顺序。用带步进条件的循环帧内/跨视角注意力迭代 16 步，分别预测相机局部点图、相对位姿和全局度量尺度，再经 MoGe3 风格的稀疏 3D U-Net 细化细薄结构表面。训练中截断相机平移对局部点归一化的梯度回传，单这一项就让相机位姿损失下降 **10.9%**。
- **几何条件化的运动分支（整体 ~0.5B）**：冻结几何分支防止破坏重建精度；运动分支同样用 8 步循环解码器（无时序编码），通过 **Spatial AdaLN** 注入几何特征，让 2D 对应匹配直接借用跨视角几何线索（消融显示整体 EPE 降 **7.17 px**，大基线对降 **8.10 px**）。跟踪头输出 2D 对应 $\mathbf{U}_{q\to i}$ 后，直接采样目标帧度量点图 $\mathbf{Y}_{q\to i}(\mathbf{u})=\mathbf{X}_i^{\text{metric}}(\mathbf{U}_{q\to i}(\mathbf{u}))$ 得到世界系 3D 轨迹；另融合冻结 SAM 2 特征预测运动物体掩码。
- **面向野外的三路数据配方**：(1) Funes/Sketchfab 场景级渲染 + 广角/滚转/畸变增强；(2) 互联网动态视频先抠除前景做视频修复，用旧版模型重建纯背景，再只保留原始可见背景像素作为伪标签配回原视频；(3) 联合构建的 GameRealm 提供引擎原生动态几何与持久轨迹。

**第 6 节最有价值的工程结论**：
- **Spatial AdaLN 几何条件**让大基线视角跟踪误差大降 8.10 px；
- **中层视觉特征更适合几何**：DINOv3 取第 11+17 层并以极低学习率微调，显著优于末层特征或冻结/高学习率微调；
- **循环步进条件**让循环解码器在训练后期反超非循环基线（相机损失降 10.2%）。[实验与消融：第 5–6 节](https://arxiv.org/html/2611.23144v1#S5)。

## 总结讨论

π⁴ 是目前 4D 基础模型中把**“轻量架构、长程稳定、度量尺度、轨迹—表面一致性”**平衡得最出色的一篇工作。它最精妙的地方在于把 3D 跟踪拆回 2D 对应 + 目标几何抬升：既省掉了重复学习 3D 位置的负担，又天然消除了轨迹与重建表面打架的老毛病。

放在具身智能与 4D 世界模型的语境下看，π⁴ 非常适合作为**免标定的 4D 感知前端与在线度量测量/验证器**（例如用来检验策略动作在真实世界里是否兑现了预期 4D 位移）；但它本质上是**被动感知器**，不包含动作条件推演、接触物理建模，也没有面向控制的跨遮挡持久记忆。

## 局限、失败案例与开放问题

- **相机运动与前景运动混淆**：静态背景纹理稀少或移动前景占画面主导时，模型仍可能把前景当静止背景，导致重建与真实静态场景矛盾。
- **远离坐标原点时位姿误差增大**：作者观察到相机离重建原点越远，平移误差越大，说明位姿估计对绝对平移的数值尺度仍敏感。
- **超长序列精度仍不及传统优化**：虽可单次前向跑通几百至上千帧不 OOM，但在远超 64 视角训练长度的序列上，全局一致性仍不能稳定匹敌传统 SfM/BA 优化。
- **遮挡点的 3D 抬升受限**：解析抬升只在目标帧可见表面上成立；完全遮挡点的 3D 位置无法通过目标表面直接采样获得。
- **纯被动感知边界**：不含动作条件预测与物理动力学，在机器人闭环中需与世界动作模型或规划验证器配合。
