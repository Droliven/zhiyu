## 当前挑战

要把单图、无序多图和长视频的 4D 感知（几何、位姿、绝对度量尺度、3D 点轨迹与运动分割）统一进一个免标定前馈基础模型，现有方法卡在三个彼此纠缠的底层矛盾上：

- **直接回归 3D 轨迹的“误差耦合病”**：像 ARROW 那样直接输出参考系下的 3D 轨迹端点，本质上是逼单个预测头同时承担“像素对应 + 目标深度 + 相机外参 + 全局尺度”四重误差——相机稍一拉远或基线一拉宽，预测出的 3D 轨迹就会飘离重建出的场景表面；而像 MoSE3 那样另起一套跟踪深度头，又会与主几何分支自相矛盾。
- **参数臃肿锁死了训练上下文长度**：主流 3D/4D 基础模型普遍在 1B–1.7B 参数量级，显存全被参数和激活吃光，训练期只能看十几帧短窗口；推理期面对几百到上千帧的大场景单次前向，轻则尺度/位姿严重漂移，重则直接 OOM（如 VGGT、DA3-Giant、Track4World 在 Oxford Spires 上全线 OOM）。
- **野外动态视频的监督真空**：互联网真实动态视频没有深度和相机外参真值，直接拿传统 SfM/MVS 跑伪标签又会被画面里的移动人/车/手带偏。

## 研究动机

**核心 Insight：4D 感知不应把所有任务揉进一个重型黑盒，而应做两次干净的解耦——（1）用“带步进条件的循环权重共享”把参数砍半，把省下来的显存全部换成 64 视角超长训练上下文；（2）冻结几何底座，让运动分支只管尺度无关的 2D 对应，再用目标帧度量几何把 2D 点解析抬升回 3D 表面。**

这背后的三条设计逻辑严丝合缝：

- **循环权重共享的真正红利是“上下文长度”**：沿用 DVLT（DéjàView Looped Transformer）思路，把几何与运动解码器都改为带显式步进条件 $\tau$ 的循环块，将全系统压到 **~0.5B 参数（几何仅 343M）**——省下的显存不追求空洞的轻量排名，而是直接用来撑起 **64 视角联合训练上下文**，从而赋予模型单次前向吃下数百上千帧的泛化能力。
- **构造级消除轨迹—表面脱节**：冻结几何分支并施加 stop-gradient（防止噪声动态梯度污染静态度量几何），通过 **Spatial AdaLN** 把同视角/同 Patch 的几何特征注入循环运动解码器，让运动分支借着 3D 几何线索只预测 2D 稠密对应，最后直接采样目标帧度量点图 $\mathbf{Y}_{q\to i}(\mathbf{u})=\mathbf{X}_i^{\text{metric}}(\mathbf{U}_{q\to i}(\mathbf{u}))$——只要点可见，3D 轨迹从数学构造上就不可能飘离表面。
- **三路互补数据补齐野外动态短板**：用大场景合成渲染补广角/滚转鲁棒性，用“抹掉前景+视频修复→重建纯背景→回贴可见背景掩码”从互联网动态视频榨出干净几何伪标签，用引擎原生 GameRealm 补长程动态 3D 轨迹。

## 技术方案

**输入**：任意数量的未标定 RGB 图像（单图、无序图集或长视频，无需时间顺序）；跟踪任务额外指定查询视角。

**过程**：共享 DINOv3（取第 11+17 中层特征低学习率微调）编码后，先由无参考帧 16 步循环几何解码器联合稀疏 3D U-Net 细化恢复每帧度量点图与相机位姿；再冻结几何并截断梯度，将其特征经 Spatial AdaLN 注入 8 步循环运动解码器，预测 2D 稠密对应与运动物体掩码，并将 2D 对应直接解析采样抬升到目标帧度量 3D 表面。

**输出**：单次前向统一输出每帧度量 3D 点图、相机外参、全局度量尺度与几何置信度，以及多图下的 2D/3D 点轨迹、可见性与运动物体掩码。

核心模块与工程细节拆解（[方法：第 3 节](https://arxiv.org/html/2611.23144v1#S3)）：

- **无参考帧 16 步循环几何底座（343M）**：继承 $\pi^3$ 的置换等变对称建模（不钦定第 1 帧为参考帧，消除首帧退化风险）。同一对帧内/跨视角注意力块循环迭代 **16 步**，每步注入显式**循环步进条件 $\tau$**，使模型明确区分前期粗对齐与后期精细度量校准；输出经 MoGe3 风格稀疏 3D U-Net 细化细薄结构。训练期截断相机平移对局部点归一化的梯度回传，单项即让相机位姿损失下降 **10.9%**。
- **冻结几何条件化的 8 步循环运动分支（全系统 ~0.5B）**：训练运动分支时**完全冻结几何分支并施加 stop-gradient 路由**，避免动态前景监督破坏静态几何精度。运动解码器执行 **8 步**无时序编码循环，每步经 **Spatial AdaLN** 注入同位置几何 Token，让跨视角 2D 匹配直接读取三维结构先验；再融合冻结 SAM 2 特征输出运动物体掩码。
- **抗偏置三路数据配方**：(1) Funes/Sketchfab 场景级渲染 + 广角/滚转/畸变增强；(2) 互联网动态视频“抠前景→视频修复→旧模型重建纯背景→仅保留原始可见背景像素作伪标签”；(3) GameRealm 引擎原生动态几何与持久轨迹。

**第 6 节最具实操价值的四条消融结论（直接可复用）**：
1. **循环步进条件 $\tau$ 是循环反超非循环的分水岭**：给共享块显式喂入当前循环步数后，循环解码器在训练后期**反超非循环基线**，相机位姿损失再降 **10.2%**；
2. **Spatial AdaLN 几何注入极大改善大基线跟踪**：注入冻结几何特征使整体跟踪 EPE 降 **7.17 px**，大基线困难视角对降 **8.10 px**；
3. **中层视觉特征 + 极低学习率微调最适合几何**：DINOv3 取第 **11+17 层**并低学习率微调，显著优于末层语义特征、完全冻结或高学习率微调；
4. **平移归一化梯度截断**：单靠截断平移对局部点归一化的梯度回传，相机位姿损失直降 **10.9%**。[实验与消融：第 5–6 节](https://arxiv.org/html/2611.23144v1#S5)。

## 总结讨论

### 核心 Takeaway 与可迁移启示

1. **给做 Looped Transformer 的人：循环权重共享最大的红利未必是“省推理 FLOPs”，而是“省出显存直接拉爆上下文窗口”**。π⁴ 在 Oxford Spires 361–800 帧上把 1.3B+ 竞品全部逼到 OOM，自己却以 0.73 m ATE 单次前向通关，核心就在于用 0.5B 循环结构换来了 64 视角联合训练——这是视觉/多模态长上下文建模极其干净的破局方式。
2. **给做多任务 3D/4D 模型的人：用“冻结底座 + Stop-Gradient + Spatial AdaLN + 解析抬升”替代端到端硬拼多头**。强行让几何和动态运动端到端互相回传梯度往往两败俱伤；先冻住干净的度量几何，再把 3D 跟踪降维成“几何条件化 2D 对应 + 目标表面采样”，既省算力又从根上消灭表面漂移。
3. **给做具身智能与世界模型的人**：π⁴ 已经具备充当下一代机器人**免标定 4D 感知前端**与**在线执行验证器（Verify in 4D）**的工程成熟度——例如在真机执行后直接用纯 RGB 核验机械臂与物体是否兑现了预期度量位移，而无需外参标定与昂贵深度相机。

### 批判性审视与适用边界

π⁴ 本质上仍是**纯被动感知器**，不懂动作干预与接触物理，也无法在完全遮挡下通过目标表面采样恢复不可见点的 3D 位置（解析抬升的硬币反面）。在强遮挡具身操作里，必须将它与具备跨遮挡记忆或动作条件推演的世界模型（如 Loop4D 或 4D WAM）耦合使用。

## 局限、失败案例与开放问题

- **相机运动与前景运动混淆**：静态背景纹理稀少或移动前景占画面主导时，模型仍可能误将前景当静止背景，导致重建与真实静态场景矛盾。
- **远离坐标原点时位姿误差放大**：作者指出相机离重建原点越远，平移误差越大，说明位姿回归对绝对平移数值尺度仍敏感。
- **超长序列全局一致性仍逊于传统 SfM/BA**：虽能单次前向跑通几百至上千帧不 OOM，但在远超 64 视角训练窗口的超大规模场景中，全局闭环精度仍不及经典全局捆绑调整。
- **完全遮挡点的 3D 抬升失效**：2D 对应解析抬升在数学上依赖目标帧表面可见；点被遮挡时无法直接从目标点图采样，需额外遮挡推理或跨时记忆补全。
- **无动作条件与物理动力学**：纯被动感知边界决定了它不能直接替代动作条件世界模型，需在机器人闭环中与策略/规划器配合。
