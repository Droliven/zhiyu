## 当前挑战

空间问答中的失败不一定来自感知模型。即使工具给出正确的分割、坐标和运动，VLM 仍可能颠倒观察者、误读坐标系、遗忘中间证据，或凭图片直觉推翻测量结果。继续增加工具不足以解决“测到了，但没有用对”的接口缺口。

## 研究动机

**把通用编程 Agent 已有的检查与修订能力用于空间推理，并让工具接口负责保存和解释证据。** Agent 选择要测什么；工具将结果写入可按名称查询的场景记忆，并把数值转成带单位、参考系和方向含义的空间陈述。贡献主要是场景状态、模型与工具之间的接口设计，VLM 与感知模型均不进行本工作新增训练。

与本库的空间推理、3D 感知和 Agent 工具使用直接相关；与机器人策略间接相关，可借鉴其对象身份、观察者参考系和证据读出接口，当前实验尚未检验动作执行。

## 技术方案

**输入**：空间问题及多视角图片或视频帧，外加固定的工具教程与推荐工作流。主实验使用 OpenHands 承载 Qwen3.8-27B（FP8）或 Gemini-3.8-Flash。

**过程**：Agent 通过普通 shell 调用感知 CLI。Depth Anything 3 恢复米制几何与相机位姿，GeoCalib 对齐重力方向，π³-MOS 提供运动掩码，SAM 3 根据文本分割对象。工具维护每个问题 episode 内的场景记忆，保存原帧、融合点云，以及有名称的位置、范围和可选 6-DoF 位姿。Agent 可添加问题隐含的观察者、修改朝向或删除错误实例；距离、深度、方位、运动等读出从存储几何计算，并同时返回数值与空间语言结论。

**输出**：空间问题的最终答案，以及可检查的测量、实例注册和图像文件；不输出机器人控制动作。

区别于专用状态机 Agent，它保留通用编程 Agent 的文件、看图、代码执行与修订能力，通过同一工作区检查感知结果。记忆是外部几何状态，而非要求模型在不断变长的对话中复述全部测量。读出声明对象、单位、参考系和方向，减少把裸数值重新翻译为题目关系时的错误。[方法与工具接口：正文第 2 节、附录 B](https://arxiv.org/html/2610.28354v1#S2)。

## 实验结果

评测包括 MMSI-Bench、MindCube、SPAR-Bench、MMSI-Video-Bench 和 ReVSI。主比较保持相同 VLM 骨干与感知后端；“同一编程 Agent 有/无工具”更直接衡量整套工具接口的增益，单组件消融则检验记忆、语言解释和模型写入接口的作用。

| 设置 | MMSI-Bench | ReVSI | 解释 |
| --- | ---: | ---: | --- |
| Qwen3.8-27B，通用编程 Agent 无工具 | 52.6 | 61.8 | 与完整系统相同 Agent、相同题目 |
| Qwen3.8-27B，SpatialClaw | 62.6 | 74.5 | 相同骨干与感知后端的专用 Agent 对照 |
| Qwen3.8-27B，S-Agent 2.0 | 66.5 | 82.3 | 相对自身无工具基线提升 13.9 / 20.5 点 |
| Gemini-3.8-Flash，通用编程 Agent 无工具 | 62.9 | 80.9 | 更强骨干的对应对照 |
| Gemini-3.8-Flash，S-Agent 2.0 | 74.1 | 90.5 | 工具仍带来 11.2 / 9.6 点增益 |

MMSI-Bench 为总体准确率；ReVSI 按题型宏平均，其中数值题用官方 mean relative accuracy、其余题用选择准确率，因此 **82.3 是协议总体得分，不宜写成全部问题统一计数的准确率**。ReVSI 主表中 Agent 使用 64 帧。

Qwen 骨干消融：删除场景记忆后 MMSI/ReVSI 降至 63.0/79.8；删除解释式读出为 65.2/81.1；禁止模型添加或删除实例降至 57.7/76.4。这支持三部分都有作用，其中允许模型把题意写入场景的接口影响最大。相同工具也可运行在 Codex 和 Claude Code，但 ReVSI 分别为 76.6 和 79.1，低于 OpenHands 的 82.3，表明外层 Agent 的差异仍影响结果。[表 1–6 与评测口径](https://arxiv.org/html/2610.28354v1#S3)。

## 总结讨论

核心启发是把空间证据做成可保留、可修改且可解释的接口：VLM 负责语义选择与证据组织，专门工具负责几何测量，统一场景状态连接两者。它展示了无需训练新基础模型的测试时能力提升，不意味着推理免费，也未证明获得通用机器人控制能力。

局限也集中在接口入口：题目要求想象一个观察者时，Agent 可能注册错误位置或朝向；题目问物体自身高度时，可能误测物体离地高度。持久记忆能保留错误证据，解释式读出也可能流畅地解释错误测量，因此仍需检验问题到测量的 grounding。[定性失败：正文第 3.4 节、Fig. 4](https://arxiv.org/html/2610.28354v1#S3.SS4)。

## 局限、失败案例与开放问题

- 证据来自空间问答基准，没有机器人策略、闭环操控或真实硬件任务成功率。
- 无新增训练依赖预训练 VLM 与多个冻结感知模型的既有能力；重建、分割和坐标误差仍会传播到答案。
- 问题中的想象视角与被测量的物理量可能被错误 grounding；绝对距离类别并非最优。
- 场景记忆在单 episode 内持久，不是跨任务终身学习；Agent 检查与工具调用的时间、token 成本缺少充分统一比较。
- 整体接口和 harness 对照并非只改变一项因素；消融支持组件在当前实现中的作用，不能扩大为所有骨干与任务的普遍因果结论。
