## 当前挑战

从单张参考图沿任意相机轨迹生成可探索、几何一致的 3D 场景视频，现有视频世界模型（VDM）主要卡在两类记忆范式的结构性失效上：

- **2D 图像记忆（DFoT、Context-as-Memory 等）缺乏显式三维拓扑**：把历史帧当作外部记忆库虽能维持短时连贯，但面对大范围平移、急转弯或闭环重访时，没有显式 3D 遮挡与视差约束，极易出现尺度漂移、透视畸变与闭环错位；在剧烈相机运动下甚至退化为近乎静止的画面。
- **重建式 3D 代理（ViewCrafter、GEN3C、Voyager）陷入“不完整—幻觉—自污染”死循环**：静态点云代理只包含首帧可见区域，未观测区域永远欠约束，迫使 VDM 随机脑补；而增量式点云代理（如 Voyager）将 VDM 新生成的帧反复反投影回点云，结果代理本身的完整性反过来受制于 VDM 脆弱的 3D 感知力——一旦某帧出现幻觉或光照漂移，就会固化进 3D 代理并持续毒害后续帧。
- **单图原生 3D 场景生成的坐标系失配与数据真空**：直接借用物体级原生 3D 生成器（如 TRELLIS）生成场景，缺乏视图坐标系对齐监督，微小位姿偏移在场景尺度下被急剧放大，导致代理渲染与参考图错位并误导下游 VDM；同时社区缺乏兼具室内外多样性与精准几何标注的大规模单图场景数据集。

## 研究动机

**核心 Insight：与其让视频扩散模型一边猜测被遮挡的 3D 结构一边画像素，不如彻底拆分成“一次性生成全局对齐的 3D 代理 + 图形学延迟渲染式的视频扩散精修”——用原生 3D 生成器在视频生成之前先锁定全局几何拓扑，再把 VDM 降维成只负责补高频纹理与修补代理瑕疵的 Generative Deferred Refiner。**

这一范式相较于重建式代理与全景图代理有三层不可替代的优势：

- **从“无约束 3D 生成”变为“点锚定稀疏体素补全”（PaSS-Flow）**：将首帧 RGB 与预测深度反投影并体素化，作为显式几何锚点 $\mathcal{V}_{\text{cond}}$ 通道拼接进稀疏结构流匹配，强迫原生 3D 生成器在参考视角坐标系下精准生长出不可见区域，从源头消灭场景级 3D–2D 空间错位。
- **比全景图代理（Matrix-3D、One2Scene）多出真实视差与遮挡推理**：全景图本质上仍锁定在单一光心，大平移下无法表达前后景遮挡关系；原生 3D SLAT/3DGS 全局代理直接建立在体素化的 3D 空间中，天然支持任意 $SE(3)$ 轨迹下的真实视差与重访闭环。
- **“数据剥离对照”证明收益来自架构而非单纯堆数据**：作者用自建 115K 数据重训了增量式代理代表 Voyager（记为 Voyager†），尽管其 FVD/PSNR 显著提升，但在大运动下的几何一致性（RPE/RVE）仍远远落后于 SpatialCrafter，直接证实“一次性全局生成式代理”才是压制长程漂移的决定性机制。

## 技术方案

**输入**：单张参考 RGB 图像 $\mathbf{I}_0 \in \mathbb{R}^{3\times H\times W}$ 及任意长度为 $N$ 的 $SE(3)$ 相机轨迹 $\mathcal{T}=\{\mathbf{P}_i\}_{i=0}^{N-1}$。

**过程**：第一阶段先将首帧反投影体素化为结构锚点，经基于 TRELLIS 改造的 PaSS-Flow 与 SLAT Flow 生成全局 3D 高斯代理 $\mathcal{X}_{\text{scene}}$ 并沿轨迹渲染粗糙 RGB-D 序列；第二阶段将粗糙 RGB 与深度经因果视频 VAE 编码后沿宽度拼合，通过并行几何注入（Parallel Geometry Injection）与代理感知退化（Proxy-Aware Corruption, PAC）微调冻结底座 Wan2.1-Fun-Control 的 LoRA，联合精修出高保真 RGB-D 视频。

**输出**：沿目标相机轨迹时空一致、高保真且具备几何一致性的 81 帧 RGB-D 视频序列 $\hat{\mathbf{V}}=\{\hat{\mathbf{I}}_i,\hat{\mathbf{D}}_i\}_{i=1}^{N-1}$。

核心模块与数据工程拆解（[方法：第 4 节](https://arxiv.org/html/2608.27073v2#S4)）：

- **点锚定稀疏结构流匹配（PaSS-Flow）**：基于 TRELLIS 的两阶段 SLAT 架构（稀疏体素结构 + 每体素潜在特征 → 3DGS 解码器 $\mathcal{D}_{\text{3D}}$）。将 $\mathbf{I}_0$ 与深度反投影并按 $\mathbf{P}_0$ 变换体素化得到条件体素 $\mathcal{V}_{\text{cond}}$，与噪声状态 $\mathcal{V}_t$ 在 DiT 输入端通道拼接，以流匹配目标 $\mathcal{L}_{\text{PaSS}}$ 完成稀疏体素补全，再经 SLAT Flow 解码出全局 3DGS 代理。Stage 1 在 16×H20 上分阶段微调（RE10K+DL3DV 10K 步 → SpatialGen 10K 步，batch size 128）。
- **并行几何注入（Parallel Geometry Injection）**：对 3DGS 渲染出的粗糙 RGB-D 序列分别用 Wan 因果 VAE 编码为 $\mathbf{z}_{\text{rgb}}$ 与 $\mathbf{z}_{\text{depth}}$，沿宽度维度并排拼接构成联合几何潜在 $\mathbf{z}_{\text{geo}}$，与噪声潜在 $\mathbf{z}_t$ 通道拼接，再与参考图潜在 $\mathbf{z}_{\text{ref}}$ 沿 Token 维度拼接；**冻结全部预训练 VDM 权重、仅优化 DiT 内的 LoRA**，在注入强拓扑约束的同时不破坏预训练生成流形。Stage 2 在 32×H20 上按 $256^2$（12K 步）→ $512^2$（4K 步）渐进训练（81 帧，batch size 32）。
- **代理感知退化（Proxy-Aware Corruption, PAC）**：推理时生成的 3D 代理必然存在过度平滑、浮空伪影与未观测空洞（黑洞）。训练期对条件对 $(\mathbf{I}_i^{\text{cond}}, \mathbf{D}_i^{\text{cond}})$ 随机施加三种退化——自适应高斯模糊、分块噪声、局部深度擦除——迫使精修器学会“哪里该锚定代理几何、哪里该调用视频先验主动修复与补全”。
- **115K 混合场景数据引擎**：融合合成室内数据 SpatialGen（重渲染 2.2K 高质量场景×10 轨迹得 22,421 条连续 RGB-D 视频）与真实视频 RealEstate10K（65,683 条）和 DL3DV（10,510 条，用 ViPE + Depth-Anything-v3 估计一致深度并严格过滤），经 TRELLIS 管线统一构建粗 3DGS 代理与配对渲染，并以 Gemini 3 生成文本描述，最终得到 **115,295 组图生场景对**与 **87,115 组可控视频对**。

## 实验结果

所有方法在统一的 81 帧单图长轨迹评测协议下对比（Table 1；重投影误差 RPE 与闭环重访误差 RVE 直接基于参考帧真值 RGB-D 与相机轨迹计算，排除 SLAM 估计器干扰）：

| 评测基准 | SpatialCrafter | 次优/关键基线对比 | 核心结论与归因 |
| --- | --- | --- | --- |
| **SpatialGen-Video**（104 闭环场景） | FVD **193.54** / PSNR **14.775** / SSIM **0.579** / LPIPS **0.416** / RPE **0.093** / RVE **38.69** | ViewCrafter（FVD 339.04, RPE 0.125）；Voyager†（FVD 363.39, RPE 0.192, RVE 250.98）；GEN3C（RVE 26.60, FVD 525.23） | 5/6 指标第 1，FVD 比次优直降 **42.9%**；即便同数据重训 Voyager†，RVE 仍高达 250.98 |
| **RealEstate10K**（100 真实测试场景） | FVD **148.71** / PSNR **17.185** / SSIM **0.659** / LPIPS **0.266** / RPE **0.078** | GeometryForcing（FVD 190.41, PSNR 16.46, RPE 0.093）；GEN3C（FVD 199.57, RPE 0.118） | 全部 5 项指标断层第 1，证明合成+真实混合代理引擎具备强真实场景迁移力 |
| **DL3DV**（标准测试集，大范围运动） | FVD **242.30** / PSNR **13.356** / SSIM **0.356** / LPIPS **0.453** / RPE **0.149** | GEN3C（FVD 369.99, RPE 0.189）；ViewCrafter（FVD 470.05, RPE **0.147**）；Voyager†（FVD 708.42, RPE 0.211） | 视觉质量全面第 1（FVD 降 **34.5%**），几何误差 RPE 与 ViewCrafter 持平并大幅领先其余基线 |

**Table 2 消融实验的三条硬核归因（SpatialGen-Video）**：
1. **PaSS-Flow 是全局代理可用性的生死线**：去掉 PaSS-Flow 后，3D 代理与输入视角失配，FVD 从 **193.54 暴涨至 472.07**，RPE 从 **0.093 恶化至 0.169**，RVE 从 **38.69 飙升至 153.47**（约 4 倍）。
2. **粗 RGB-D 代理远胜纯相机参数控制**：在真值粗代理消融中，纯相机控制（Camera-only）FVD 为 178.47 / PSNR 14.50 / RPE 0.107；加入粗 RGB 渲染后 PSNR 跃升至 **19.47**、RPE 降至 **0.066**；再加入粗深度（RGB-D）FVD 进一步降至 **114.13**、RVE 降至 **32.17**。
3. **PAC 有效消除训练—推理代理保真度鸿沟**：开启 Proxy-Aware Corruption 后，Full 模型 FVD 再降至 **107.03**、PSNR 升至 **20.39**、RPE 降至 **0.057**、RVE 降至 **30.96**；定性对比显示无 PAC 时精修器会忠实保留粗代理的黑洞伪影，开启 PAC 后能自主识别并逼真补全缺失区域。

## 总结讨论

### 核心 Takeaway 与可迁移启示

1. **给几何增强 World Action Model（WAM）的设计启示：用“生成式 3D 代理 + 延迟精修”替代“在线自回归重建缓存”**。机器人导航与操作常需预测大视角/遮挡后的场景演化，增量式点云缓存（如 Voyager）在长轨迹下必然遭遇误差自放大；先用轻量原生 3D 模型做一次性点锚定全局结构补全，再用冻结 VDM + LoRA 做视觉外观与深度精修，是兼顾 3D 拓扑刚性与视觉高保真的极佳解耦架构。
2. **给多模态条件注入的工程范式：宽度拼接 + 冻结底座 LoRA + 条件退化（PAC）**。当外部几何条件（粗渲染、深度图、点云投影）存在不可避免的推理期噪声时，直接用干净真值训练会让扩散模型“盲信”条件而复制伪影；PAC 这类针对性条件退化训练（模糊/块噪声/局部擦除）几乎零推理开销，却能教会模型在“锚定几何”与“调用生成先验修复”之间动态权衡。
3. **数据引擎的混合配方可复用**：合成全景室内（精准几何、可重渲染连续轨迹）+ 真实视频（ViPE/DAv3 一致深度 + 严格过滤）+ 统一 SLAT 粗代理构造，为需要配对“粗 3D—精视频”监督的世界模型提供了一条可扩展的数据生产线。

### 批判性审视与适用边界

SpatialCrafter 的核心假设是**静态 3D 场景**——全局 3D 代理在生成视频前一次性确定且不再随时间演化，因此它擅长相机探索与大视角新视角合成，但无法直接建模场景内物体的物理运动、交互碰撞或非刚体变形；同时，两阶段串行结构（TRELLIS 3D 生成 + 81 帧双向视频 DiT 精修）面向离线/分块场景探索，尚未具备逐帧流式低延迟交互能力。

## 局限、失败案例与开放问题

- **仅覆盖静态世界建模，缺乏动态物体与物理交互**：一次性静态 3DGS 代理无法表达移动主体或外力驱动的场景演化，向动态 4D 世界模型扩展需要引入时变代理或与物理动力学模块耦合。
- **两阶段流水线的延迟与非流式瓶颈**：先生成全局 3D 代理再进行 81 帧视频扩散精修，难以直接满足实时交互式具身仿真或在线控制闭环的延迟预算。
- **单图全局补全的固有不确定性与代理容量上限**：TRELLIS SLAT 稀疏体素分辨率有限，在极其开阔或结构复杂的室外大场景中，远景细节与多房间连通布局仍可能受限于代理的体素覆盖范围。
- **依赖前置单目深度与位姿估计质量**：PaSS-Flow 的点锚定严格依赖输入图深度估计精度；若输入视图存在强反光、透明材质或极端畸变导致深度失真，锚点误差会直接传导至全局代理与精修结果。
