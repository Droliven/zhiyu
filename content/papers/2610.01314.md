## 当前挑战

以 D4RT 为代表的统一 4D 重建与跟踪模型，靠“给定源像素，查询其在目标时刻和参考坐标系下的 3D 位置”打通了几何与对应关系，但它把**时序顺序写死在了架构里**：

- **顺序假设绑死输入形态**：编码器依赖时序位置编码，查询端用固定帧号表去索引图像。这天然只适合连续单目视频，无法直接处理同时刻多相机流或无序照片集。
- **换无序编码器会“失配”**：如果直接把编码器换成无序多视角几何主干（如 DA3），全局特征不再有帧号顺序，固定索引查询嵌入就会与全局特征空间脱节，找不到对应的图像。
- **局部视频训练视野太窄**：只在时间连续的短片段上练跟踪，模型容易偷懒依赖帧间微小位移与外观连续性，跨视角、大跨度的泛化能力受限。

## 研究动机

**核心思路：放弃用“第几帧”来寻址，改用图像内容自身生成的“身份编码（ID Token）”来寻址。**

DA3 这类多视角几何 Transformer 本来就会为每张图产出一个全局相机 Token，它与图像特征天然处在同一个表征空间里。ARROW 直接把它复用为每张图的 **ID Token**：不管图像集怎么打乱、是否来自同一时刻的多台相机，查询只需把源图、目标图、参考图的 ID Token 拼在一起，就能在无序全局特征中精准“叫出”对应观测。

一旦解除了顺序束缚，模型就可以把**静态多视图集、单目动态视频、多相机同步序列**放进同一个框架里非顺序混训——让跨视角大位移的困难对应监督反过来提升常规单目跟踪。

## 技术方案

**输入**：任意无序的未标定 RGB 图像集（单目视频、多相机流或静态多视图均可），以及按需指定的查询 `(u, v, src, tgt, ref)`。

**过程**：用无序 DA3 主干编码图像集并提取每帧内容 ID Token，将查询像素特征与源/目标/参考三帧 ID Token 组合后，通过稀疏交叉注意力独立解码目标 3D 状态；训练期跨视角、跨长窗口非顺序混合静态与动态数据。

**输出**：每个查询在目标时刻、参考坐标系下的 3D 位置、置信度、2D 投影、可见性与法向；按需组合查询即可统一产出稀疏/稠密 3D 轨迹、点云与相机位姿。

核心设计拆解（[方法：第 3 节](https://arxiv.org/html/2610.01314v1#S3)）：

- **内容派生 ID Token 替代时间编码**：编码器（DA3 初始化）不加任何时序位置编码，把每帧原相机 Token 复用为内容身份 $\mathbf{h}_i$（不强行解释为外参）。查询向量由三部分相加而成：源像素局部 RGB 裁剪、归一化坐标 $(u,v)$ 编码，以及 $[\mathbf{h}_{\text{src}}; \mathbf{h}_{\text{tgt}}; \mathbf{h}_{\text{ref}}]$ 的线性映射。
- **独立稀疏解码，一编多查**：图像集只编码一次得到全局上下文 $\mathbf{F}$，任意数量的查询独立向 $\mathbf{F}$ 做 cross-attention（查询间不做自注意力）。因此既能极快地查少量关键点轨迹，也能分批稠密查询做重建；相机位姿则由稀疏预测点跨帧对齐直接恢复，无需单独位姿头。
- **三类数据的非顺序混训**：19 个公开数据集按性质分别提供监督——静态场景给跨大视角的精确几何对应；带轨迹动态视频在最高 10 倍时间窗内跨帧/跨相机非顺序采样；无轨迹动态数据（如 nuScenes）仅查询同帧（$\text{tgt}=\text{src}$）以只学几何不学错误运动。

## 实验结果

| 评测任务 | ARROW 表现 | 关键对比 |
| --- | --- | --- |
| **WorldTrack**（单目 3D 跟踪，4 数据集） | 全部总分与动态子集 **APD 最高、EPE 最低**（如 ADT 93.55%，DynReplica 动态 91.47%） | 全面超越 UniQuery4R、OmniX、4RC、SpatialTrackerV2（每序列全局中位数尺度对齐） |
| **TAPVid-3D**（无内参，最长 300 帧） | 相机系 AJ **0.248** / 世界系 APD **0.385** / L1 **0.041** | 轨迹精度领先 D4RT（AJ 0.212，世界系 APD 0.346），但遮挡判断 OA（0.863）略低于 D4RT（0.899） |
| **RGB-only MVTracker**（4 相机多视角跟踪） | 平均 APD **61.0** / AJ **49.2** / EPE **0.1252** | 12 项指标中 11 项第一，大幅领先 MVTracker+DA3（APD 45.3）与 OmniX（48.0）；仅 DexYCB EPE 偏高 |
| **相机位姿与 3D 重建** | Sintel ATE **0.0613**、NRGBD Chamfer **0.0263** | 无专用位姿头，在动态位姿与室内重建上持平或超过 DA3、$\pi^3$ 等专用重建模型 |

**决定性消融（Table 6，从有序 D4RT 基线逐步演进到 ARROW）**：
- 改为内容 ID Token 寻址后，单目与多视角跟踪同步提升；去掉编码器时序位置编码基本不掉单目精度。
- 最大的性能拐点来自**非顺序跨视角采样**——多视角跟踪 APD 直接暴涨 **+28.85 pp**，且单目跟踪、位姿和重建全部受益；再补入 4 个静态多视图数据集后全部 8 项指标继续走高。[实验：第 4 节](https://arxiv.org/html/2610.01314v1#S4)。

## 总结讨论

ARROW 回答了一个很干净的问题：**如何让 4D 统一查询架构真正摆脱“有序视频”的拐杖**。用内容 ID Token 替代位置索引改动极小，却打通了静态多视图、单目视频与多相机流的统一训练，并用消融实证了“跨视角几何对应能显著反哺单目动态跟踪”。

与同期的 **π⁴** 相比，两者的路线取舍非常清晰：ARROW 直接在参考坐标系回归 3D 端点，按需稀疏查询极灵活，在多视角 3D 跟踪上占优；但它不输出绝对度量尺度，且相机远离参考帧时直接回归的 3D 端点更容易与重建表面脱节。此外，DexYCB 上 EPE 偏高与 DA3 底座本身分布失配一致，说明基础几何编码器的先验仍决定上限。

## 局限、失败案例与开放问题

- **无法时间插值或外推未来**：去掉显式时间编码后，模型只能查询输入图像集里实际出现过的观测时刻。
- **稠密重建成本高且查询无交互**：稀疏查询很快，但稠密高分辨率解码需分批跑大量查询；且查询间无自注意力，远景和低置信度区域的局部一致性较弱。
- **局部 2D 精度与遮挡判断偏弱**：TAPVid-3D 遮挡精度（OA）略逊于 D4RT，多宽高比训练下仍存在数像素级的 UV 偏移。
- **跨视角域偏移敏感**：多视角输入若混入第一视角（egocentric）等分布外视角，性能会明显下降。
- **缺少绝对度量尺度**：所有 3D 评测均依赖每序列尺度对齐，尚不能直接给出真实世界米制尺度。
