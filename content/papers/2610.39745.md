## 当前挑战

将人-物交互（HOI）生成从单物体推进到复杂多物体长时序场景，现有方法卡在两重难以靠单纯扩参或加扩散步数解决的根因上：

- **只建模人-物接触、遗漏物-物功能对齐导致的“局部合理、全局错位”**：现有多物体方法（如 HIMO-Gen、SyncDiff）主要在运动学层面通过距离或轨迹同步隐式约束多实体，缺少由交互语义决定的显式接触先验；而单物体可供性（Affordance）方法只标注人手抓握区域。在“拿起水壶往杯子里倒水”或“将中号方块叠在大号方块上再放圆柱”这类场景中，同一物体对不同交互对象暴露完全不同的功能区（壶柄对人手、壶嘴对杯口）。孤立预测人-物接触会让模型为了凑接触率而把物体黏在手上或倒向错误目标。
- **多尺度运动耦合与扁平自回归破坏全身—手部—物体因果链**：把人体根节点大幅位移、躯干姿态、精细手指操作和多个刚体/关节物体运动打包进统一潜在空间或扁平序列预测时，高幅度的全局根节点运动会直接淹没毫米级手部接触信号；同时，缺乏“先整体躯干、再精细手部、再驱动物体”的帧内因果约束，极易出现手物悬空、严重穿模或跨物体时序脱节。

## 研究动机

**核心 Insight：多物体交互的几何一致性不应指望动作生成器“盲猜”出来，而应拆分为“先推理、后交互（Reasoning-then-Interacting）”——先用 3D-MLLM 在统一空间格式下同时推理出人-物与物-物成对可供性（Unified Affordance, Unifford），再以该结构化空间先验为前缀，通过帧内由粗到细的分层解耦自回归（Root $\to$ Body $\to$ Hand $\to$ Objects）逐级合成动作。**

相比端到端扩散或级联分阶段生成的替代方案，这一设计有三层清晰优势：

- **用有向“源—目标”统一格式消融人-物与物-物壁垒**：将源物体表面上对应特定交互对象的功能区统一定义为 Unifford（人-物交互时物体为源、人为目标；物-物交互时主动发起者为源、被作用者为目标），使 3D-MLLM 能输出交错的“目标身份 + 可供性 Token”序列，在同一次推理中锁定全局多实体几何对应。
- **分层解耦量化 + FSQ 防治尺度淹没与码本坍塌**：将人体按 Root / Body / Hand 拆入三个独立码本，物体按实例级融合几何特征独立量化，并采用 Finite Scalar Quantization（FSQ）构造隐式组合码本，从表征层根治“大动作吃掉小手部”以及传统 VQ-VAE 的码本利用率低问题。
- **帧内分层自回归优于“跨全序列级联”**：相比先生成整段躯干再生成整段手部、最后生成物体的级联管线（cascaded generation），在每一帧内部按 `Root → Body → Hand → Objects` 顺序自回归既保留了全局驱动局部的因果流，又能让手部与物体的精细接触反馈及时影响下一帧的全身协调。

## 技术方案

**输入**：自然语言动作指令 $\mathcal{I}$ 及场景中 $N$ 个 3D 物体的采样点云 $\mathcal{G}=\{G_1,\dots,G_N\}$（每个物体 $P \in \mathbb{R}^{2048\times 3}$）。

**过程**：阶段一由基于 ShapeLLM-7B 微调的统一可供性推理器（UAR）联合上下文物体几何，输出交错的交互目标与 3D 稠密可供性热图；阶段二由分层交互生成器（HIG）先通过双流 FSQ 分层解耦量化器离散化人体（Root/Body/Hand）与物体运动，再经物体中心交互适配器（OCIA）将 Unifford 先验与有向关系编码为前缀条件，驱动 775M LLaMA 架构自回归 Transformer 在每帧内按 `Root → Body → Hand → Objects` 顺序生成多实体离散 Token 并解码为连续运动。

**输出**：运动学连贯且时序同步的 52 关节 SMPL-X 人体动作序列 $\mathcal{H}$ 与多物体 6D 旋转、3D 平移（及可选 2D 关节参数）序列 $\mathcal{O}=\{O_1,\dots,O_N\}$。

核心模块与关键机制拆解（[方法：第 3 节](https://arxiv.org/html/2610.39745v1#S3)）：

- **统一可供性推理器（UAR）与 InterAfford 数据集**：以 ShapeLLM-7B（冻结 ReCon++ 3D 视觉编码器 + LoRA 微调 LLaMA，$r=8, \alpha=16$）为底座，扩充 `<AFF>` 词元生成交错序列 $\mathcal{Y}=\langle I_1, \texttt{<AFF>}_1, I_2, \texttt{<AFF>}_2, \dots \rangle$。`<AFF>` 作为语义查询进入 Object-Aware Fusion 模块，与源物体交叉注意并按相关性聚合其余上下文物体特征 $f_{agg}$，再由 Affordance Decoder 结合 $\mathcal{L}_{\mathrm{ce}}+\mathcal{L}_{\mathrm{bce}}+\mathcal{L}_{\mathrm{dice}}$ 输出上下文相关的 3D 可供性掩码。采用**两阶段课程微调**（先单物体可供性对齐几何，再在自建 13,719 对含人-物与物-物关系的 **InterAfford** 数据集上微调；接触类按 $<2\text{ cm}$ 帧频率统计，非接触类如倾倒由 LASO 生成伪标签并人工精修）。
- **分层解耦量化（HDQ）**：人体运动拆为 Root（128 维，码本 512）、Body（512 维，码本 4096）、Hand（512 维，码本 4096）；物体流用 PointNet++ 提取几何关键点并加高频空间编码，与刚体运动融合后量化（128 维，码本 4096）。全部采用 FSQ 隐式标量量化，训练损失除重建项外显式加入物-物相对顶点对齐 $\mathcal{L}_{sa}$、手-物距离矩阵 $\mathcal{L}_{dist}$ 与穿透惩罚 $\mathcal{L}_{pen}$（权重 `{1.0, 1.0, 0.5}`）。
- **物体中心交互适配器（OCIA）与帧内分层自回归**：每帧构建固定槽位序列 $[z_t^{root}, z_t^{body}, z_t^{hand}, z_t^{obj_1}, \dots, z_t^{obj_K}]$（实验设 $K=3$，空槽填 `<PAD>`，超过 3 物体按时序拆分子序列自回归），并为每个槽位注入唯一 **Entity ID** 区分部位与物体实例。OCIA 将有向源—目标实体嵌入拼接过 MLP 得到关系特征 $\mathbf{r}_{i,j}$，与物体几何+Unifford 特征融合后经可学习查询交叉注意压缩为前缀条件 Token。775M LLaMA 生成器配合冻结 T5-XL 文本编码器，在训练中采用余弦退火的 Token 级 Scheduled Sampling（$\epsilon: 0.0 \to 1.0$）缓解暴露偏差；全流程单样本推理约 **8.27 秒**（4×A100 环境）。

**最具价值的四组消融归因（Table 6–8）**：
1. **去掉物-物可供性（w/o Unifford）暴露“盲目凑接触”陷阱**：在 Table 6 中，移除物-物可供性后接触率 `C%` 反而从 `0.348` 微升到 `0.366`，但碰撞率 `Coll%` 恶化到 `0.201` 且 FID 从 `1.199` 飙升至 `1.618`、R-Pre@3 从 `0.789` 跌至 `0.682`（图 8 可见垃圾桶黏手、倒茶对象错位），说明缺失物-物先验时模型只能以牺牲几何一致性为代价硬凑接触。
2. **帧内分层自回归是协调性的生命线**：换成扁平 next-token 预测（`w/o hierarchical autoregressive`），FID 崩塌至 **11.860**、接触率暴跌至 **0.066**；换成跨全序列的 `cascaded generation`，FID 也退化至 **3.380**、C% 降至 **0.256**，证明帧内逐步因果依赖远优于全序列硬级联。
3. **两阶段课程微调对 3D-MLLM 不可或缺**：直接零样本（AUC 0.4813）或仅单阶段微调（IOU $\le 0.1134$）均无法同时学好局部几何接地与多物体关系推理；两阶段微调将 AUC 拉升至 **0.8223**、IOU 翻倍至 **0.2036**（Table 7）。
4. **量化器必须人-物解耦且按部位分层**：联合量化人-物（`w/o decoupled`）重建 FID 恶化 21 倍（`0.213 → 4.625`），去掉 Root/Body/Hand 分层 FID 恶化至 `0.591`、碰撞升至 `0.216`（Table 8）。

## 总结讨论

### 核心 Takeaway 与可迁移启示

1. **给多物体 HOI 与具身操作规划：必须把“物-物功能对齐”提升到与“人-物抓握”同等的一等公民地位**。单靠手物接触无法保证工具使用、容器倾倒、积木堆叠等任务的物理合法性；将两类关系统一进有向 `<Source, Target, Affordance>` 3D 热图格式，可直接作为 VLA 或机器人技能规划器（如工具操作、装配）的显式空间接口。
2. **给全身/灵巧动作自回归生成：用“FSQ 分层解耦码本 + 帧内粗到细因果顺序”替代扁平 Token 化与跨序列级联**。FSQ 避免了多码本联合训练的坍塌难题，而帧内 `Root → Body → Hand → Objects` 在保持全局驱动局部的同时避免了级联误差不可逆累积，非常适合迁移到人形机器人全身移动操作（WBC + 灵巧手）的动作 Tokenizer 设计。
3. **给 3D-MLLM 空间推理：单物体几何接地 + 多物体关系推理的两阶段课程微调是高性价比范式**。直接用多物体小数据微调 3D-MLLM 难以收敛出精确的逐点掩码，先借单物体数据建立空间接地能力再迁移到多实体关系，可显著提升 IOU 与分布一致性。

### 批判性审视与适用边界

UniffordInteractor 本质上仍是**纯运动学、无物理仿真闭环的生成模型**：虽然 Unifford 和量化期穿透损失大幅降低了碰撞，但在 3 物体场景与 OOD 物体上 `Coll%` 仍分别达到 `0.227` 和 `0.231`；同时推理链条依赖 7B 3D-MLLM + 775M LLaMA 两套大模型（单样本 8.27s），且硬编码了 $K=3$ 的槽位上限（更长多物体任务需外部切分为子序列）。若用于真机或物理仿真角色控制，后端仍需接入物理追踪控制器或接触后优化。

## 局限、失败案例与开放问题

- **固定槽位上限与超长程切分依赖**：模型单次仅支持 $K=3$ 个物体槽位，面对包含更多物体的长时序家庭活动，需预先按时间切分为原子子序列再串联，跨子序列的全局状态一致性与过渡自然度尚未在端到端长场景中充分验证。
- **未见物体几何的运动质量退化**：在 HIMO 42 见→11 未见物体 OOD 测试中（Table 5），FID 从 `1.316` 升至 `4.587`，碰撞率从 `0.177` 升至 `0.231`，说明生成器的运动学先验对新几何拓扑仍有明显过拟合。
- **两阶段错误传播且推理延迟较高**：HIG 在训练与推理时均依赖 UAR 预测的 Unifford；若 3D-MLLM 在复杂指令下误判交互目标或可供性区域，下游自回归无法自我纠错，且 8.27 秒/样本的耗时限制了实时交互应用。
- **缺少物理动力学与大场景环境约束**：目前只处理局部交互物体集合（最多 3 个），未纳入静态环境障碍物（墙面、桌椅碰撞）及重力/摩擦等物理动力学，正如作者在结论中所指，长时程多物体与复杂人-场景交互仍是开放方向。
