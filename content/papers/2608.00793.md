## 当前挑战

当操作目标在机器人推理与执行期间持续运动（传送带、转盘、弹跳物体）时，传统 VLA 与 WAM 会撞上两重硬伤：

- **单帧观测存在运动歧义**：只看当前帧根本分不清物体正在向左还是向右、快还是慢，相同画面对应的正确接触动作截然不同。
- **渲染光流丢了“绝对速度与时间”**：直接把历史光流渲染成 RGB 喂给视频编码器，每帧按 99 分位归一化会彻底抹掉绝对位移尺度，且图片本身不含帧间耗时 $\Delta\tau$，策略无法算准何时出手拦截。
- **同步块执行赶不上动态目标**：大骨干在动作块边界同步推理会产生停顿，刚算出的轨迹还没执行完，目标就已经移走。

## 研究动机

**核心思路：用“双路径运动条件”把“运动在哪、往哪动”和“动多快、多久动”拆开喂给 WAM 的视频与动作双专家，再用异步执行（RTC）藏住推理延迟。**

- **视频路径吃“历史光流图”**：把最近 4 个时间段的稠密光流渲染为 RGB 帧，直接拼在当前帧前过冻结视频 VAE——不改动作空间、不加新编码器，就能让未来视频预测看懂空间运动结构与方向。
- **动作路径吃“显式运动学 Token”**：从同一批光流场提取 12 维物理统计量（位移、时间间隔、速度、加速度）映射为运动学 Token 注入动作专家，补回光流归一化丢掉的幅值与节拍。
- **蒸馏轻量骨干 + RTC 异步执行**：蒸馏 Wan2.2-5B 为轻量视频专家，真机部署时用 Real-Time Chunking 在执行当前动作块的同时并行预测下一块并平滑衔接，消除边界停顿。

## 技术方案

**输入**：多视角当前 RGB 观测、语言指令、本体关节状态，以及固定头部相机最近 4 段历史光流场与对应时间戳。

**过程**：视频侧将前后向一致性过滤后的 4 帧归一化光流 RGB 与当前观测拼入冻结视频 VAE；动作侧将每段光流的 12 维运动学描述符（位移/时长/速度/加速度）映射为运动学 Token 注入动作专家；两路在蒸馏轻量 WAM 内经逐层联合世界—动作注意力流匹配去噪，真机部署叠加 RTC 异步块衔接。

**输出**：16 步关节位置动作块（耦合未来视觉潜变量预测）；动作解码头仅读取原状态—动作 Token，保持机器人动作接口不变。

核心设计拆解（[方法：第 3 节](https://arxiv.org/html/2608.00793v2#S3)）：

- **历史光流条件（空间结构与方向）**：在动作块边界向前回溯 $K=4$ 个等步间隔，用 Farnebäck 光流加前后向一致性掩码去除伪影，按 99 分位归一化渲染为 RGB 帧并沿时间轴拼到当前观测前送入冻结视频 VAE。
- **12 维运动学 Token（尺度与时间节拍）**：针对归一化抹除尺度的问题，直接从有效光流像素计算平均/99 分位位移、时间间隔 $\Delta\tau_k$、速度及相邻段差分加速度，经 MLP 投影为 Token 插入动作流参与全部联合注意力层。
- **RTC 异步执行（隐藏延迟）**：DOMINO 仿真评测严格遵守原生同步协议；真机部署引入 RTC 在当前块执行期间后台预测下一块并平滑融合，专门缓解复杂运动下的感知—执行滞后。

## 实验结果

| 评测基准 | DynamicWAM 表现 | 核心对比与设置 |
| --- | --- | --- |
| **DOMINO Level 1**（35 任务同步协议） | SR **38.2%** / MS **53.2**（延迟 173.7 ms） | 超越最强基线 InternVLA-A1.5（29.3% / 42.5）+8.9 pp 且快约 3.2×；超越 PUMA（17.2%）与 $\pi_{0.5}$（9.6%） |
| **真机 12 任务**（Franka，直线 L1 / 圆周 L2 / 复合 L3） | 平均 **46.67%**（L1 70.0% / L2 51.3% / L3 18.8%） | 超越 $\pi_{0.5}$（23.75%）**+22.9 pp**、DynamicVLA（21.25%）；L3 复合运动外部基线全为 0% |
| **视觉 OOD 泛化**（L1 背景/光照/颜色偏移） | OOD-SR **36.3%**（保留率 0.52） | 绝对值高于 $\pi_{0.5}$（17.5%），但相对保留率与基线（0.54）相近，增益主要来自更强的域内动态能力 |

**关键消融证明双路径与异步执行严格互补**：
- **DOMINO 消融**：无运动条件 22.7% → 仅历史光流 27.2% → 仅运动学 Token 30.5% → **双路径 38.2%**（比更强单路再涨 +7.7 pp）。
- **真机消融（Table 2–3）**：无运动条件 25.0% → 仅光流 36.25% → 仅运动学 Token 40.0% → 同步双路径 42.08% → **+RTC 异步 46.67%**（L3 复合运动上 RTC 额外带来 +6.25 pp）。[实验：第 4–5 节](https://arxiv.org/html/2608.00793v2#S4)。

## 总结讨论

DynamicWAM 精准指出了一个很容易被忽略的表示陷阱：**把光流渲染成图像喂给视频模型时，逐帧归一化顺手把决定拦截时机的“绝对速度”给抹掉了**。用“视频侧光流保空间形态 + 动作侧运动学 Token 补幅值节拍”的双路径设计非常干净，且 DOMINO 同步与真机异步消融边界划得很诚实。它的主要短板在于运动提取仍停留在**固定外部相机的 2D 像素空间**，缺少目标实例隔离与 3D 运动建模，面对多动干扰物、遮挡或相机移动时容易受扰。

## 局限、失败案例与开放问题

- **依赖固定外置相机的 2D 光流**：无法区分指令目标与其他移动干扰物，在杂乱动态背景、遮挡或视角变动下光流统计容易失真。
- **缺少 3D 运动与深度速度建模**：纯 2D 像素光流难以处理沿相机光轴方向的逼近/远离运动，距离真正 3D/4D 动态拦截仍有差距。
- **视觉 OOD 相对保留率未显著提升**：表 4 显示背景/光照偏移下的相对保持率（0.52）与 $\pi_{0.5}$（0.54）持平，背景变化仍是最大短板。
- **复合运动绝对成功率仍偏低**：在弹跳、平动+转动等 Level 3 复合运动上仅 18.75%，且高速接触瞬间尚无自适应变时域或触觉闭环机制。
