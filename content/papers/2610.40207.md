## 当前挑战

任务级指令只给最终目标，缺少中间动作和切换时间；已有子任务标注又存在词表、粒度及边界差异，难以跨来源共同训练。逐轨迹精细人工标注昂贵，通用视频模型也难准确定位抓取、松开等短暂物理事件。

## 研究动机

**RoboAtom 为已有机器人示范建立统一的“技能类别＋动作描述＋起止时间”监督层。** 它利用重复任务的动作顺序结构，将少量人工种子标注传播到更多轨迹，再用质量控制校正；这比只为整段视频生成一句任务描述提供更明确的时间与动作结构。其贡献主要是数据、构建流程和评测接口。

## 技术方案

**输入**：多源机器人视频与状态/动作记录，以及人工校验的种子轨迹；PhysExtend 要求目标轨迹与参考具有相同的有序原子动作结构。

**过程**：先统一词表与分段规则；PhysExtend 利用夹爪事件、关节/末端运动进度、停顿和底盘状态，以有序候选边界的动态规划传播分段，再做语义和边界质量检查。整理为 RoboAtom-Data，建立 RoboAtom-Bench，并训练自动标注模型 RoboAtom-Anno；下游用原子动作条件训练执行器，由 System 2 选择当前步骤。

**输出**：时间对齐的原子动作标注、自动标注模型与技能条件策略接口。标注类别不是已经验证可任意组合调用的通用技能库。

数据汇总约 145 万轨迹、688 万片段、16,882.1 小时，覆盖 29 类统一技能。基准含 500 轨迹，分短、中、长序列与多视角子集；标签准确和时间重合需分别评测。[数据与方法第 3–5 节](https://arxiv.org/html/2610.40207v1#S3)。

## 实验结果

| 证据 | 作者报告结果 | 解释 |
| --- | --- | --- |
| 自动标注 | RoboAtom-Anno-9B 的 Skill F1@0.7 为 30.1；最强通用对比为 21.4 | 同时要求技能类别正确和时间 IoU≥0.7，不是单纯分类准确率 |
| 标注序列长度 | 9B 在短序列为 71.1，长序列为 17.3 | 长任务的细粒度分段仍明显困难，不能只看总体领先 |
| 长程控制 | LIBERO-Long 95.00%→98.20% | 相同后训练预算、观测和动作空间；同时改变原子条件与上层调度 |
| 扰动鲁棒性 | LIBERO-Plus 总体 84.05%→88.18% | 共 10,030 次评估；并非所有子项都改善 |
| 双臂操作 | RoboTwin Clean/Random 平均 64.37%→66.17% | 原子动作条件与分层执行整体方案的收益 |

控制实验双方均关闭图像增强，避免其在特定基准上降低基线表现；主结果支持整套监督与执行方案，不能单独归因于数据标注。论文明确尚未验证这些标注在大规模策略预训练中的作用。[实验表 3–4 与附录 C](https://arxiv.org/html/2610.40207v1#S5)。

## 总结讨论

价值在于把跨数据源的动作语义与时间边界变成可复用监督，连接自动标注和分层控制。它与 GroundingPI 的精确空间定位互补：一个补动作的时间结构，一个补视觉 grounding；两者均需在固定策略和预算下检验对控制的独立作用。

## 代码与数据

官方 GitHub 提供构建/评测及模型使用入口，仓库标明 MIT；Hugging Face 数据页提供 RoboAtom-Bench 与标注资源入口、模型页提供自动标注模型。源数据来自多个既有集合，新增标注的许可不自动覆盖全部原视频；完整重建语料需逐来源取得数据。本次未下载全集或运行模型。

## 局限、失败案例与开放问题

- PhysExtend 依赖相同动作顺序，重试、跳步或任务结构变化会破坏传播假设。
- 长序列精确分段仍弱，500 条基准不能覆盖所有本体、任务与粒度。
- 控制增益同时涉及原子动作条件与 System 2 调度，尚未隔离标注本身的全部作用。
- 主要验证下游适配，未建立大规模策略预训练、任意技能组合或真机泛化收益。
- 人类第一视角尚未纳入主体数据，短暂且碎片化的人类动作需要重新设计标注粒度。
