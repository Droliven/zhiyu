## 当前挑战

让人形机器人完成上下楼梯拾物、崎岖地形捡垃圾、开柜门、搬箱分拣等长程全身移动操作（Whole-Body Loco-Manipulation），当前两大主流路线各有一道迈不过去的坎：

- **端到端策略的“遥操作数据税”**：直接采集海量人形遥操作数据或构建任务专属仿真环境训端到端策略，成本极其高昂，且换一台实体机器人、换一间房间或换一种物体就容易性能骤降。
- **“高层 VLM + 底层全身跟踪器”的物理断层（4% 死亡陷阱）**：即便用 VLM 读懂一段人类示范视频、把人类动作重定向（Retargeting）给冻结的全身跟踪器，现实里依然几乎全军覆没（ATLAS 实测无学习器基线成功率仅 **4%，16/378**）。根因在于**信息错位**：高层 VLM 不知道这台实体机器人在未标定房间里的视角外参偏差、手臂重定向误差、地面摩擦与接触偏移；而冻结的底层跟踪器只管跟踪参考姿态，既不知道自己抓空了，也不会从失败中改错。

## 研究动机

**核心 Insight：不要试图在离线预训练阶段解决一切问题，而应按“谁知道什么、何时才能知道”做精准分层——任务语义在部署前由 System 2 从 1 段人类视频读出；全身平衡由冻结的 System 0 兜底；而最难提前标定的“实体机器人—当前环境残差动力学”，必须留到部署现场由 Agentic Harness 通过机器人自己的真实试错在线学出来。**

这一分工一针见血地切中了当前具身智能最核心的工程矛盾：

- **把高维难题降维成低维在线适应**：冻结全身跟踪器已经把几十个自由度的平衡与步态压缩成了稳定的指令接口；Harness 只需在低维任务空间里学习小幅控制修正量 $u_t$，就能把“差几厘米抓空”变成稳定命中，根本不需要微调任何底层权重。
- **用在线基于模型强化学习（Online Model-Based RL）打穿样本效率瓶颈**：真机现场只有几十次试错预算，无模型 RL（Model-Free RL）根本学不动，而简单常值偏置估计（RLS）又抓不住随姿态/位置变化的非线性误差；唯有在 Harness 里在线拟合局部残差动力学模型并做前向规划，才能在几十次真实尝试内把成功率拉过 80%。

## 技术方案

**输入**：**单段人类示范视频**、一句自然语言任务指令，以及人形机器人头部机载 RGB-D 相机的实时视觉反馈。

**过程**：部署前由 System 2（VLM Agent）一次性解析视频与指令生成可执行任务规范，同时将人类视频重定向为全身参考轨迹；部署中由 Agentic Harness 结合机载 RGB-D 与分割模型（SAM 类）定位目标、驱动冻结的 System 0 执行，并在每次真实尝试后检测成败——若失败则原地自主重试，并用 **Online Model-Based RL** 基于真实执行残差持续更新修正项 $u_t$。

**输出**：零遥操作、零任务专属仿真预训练、可在真实环境中越试越准的自主人形全身移动操作行为。

三层职责与闭环机制拆解：

- **System 2（高层 VLM Agent，会话前一次性推理）**：只负责“部署前就能知道的事”。读取单段人类视频和自然语言指令（例如“下楼梯捡起薯片袋再走回楼上”），一次性写出结构化任务规范——包含子任务步骤拆解、指定末端执行器、关键接触事件，以及供下游视觉分割模型（SAM）追踪物体与接触点的语言提示短语。
- **System 0（冻结全身运动跟踪器，物理先验底座）**：只负责“跨任务不变的底层物理”。将人类视频重定向得到的全身运动作为空间参考，在部署全程保持权重完全冻结，守住人形平衡与安全运动边界。
- **Agentic Harness（运行时编排 + 测试时在线残差学习器）**：负责“只有真正动手后才知道的事”。
  - *在线感知与自主重试闭环*：通过头部 RGB-D + SAM 实时观测目标与接触状态，一旦发现抓空或落位偏差，不依赖人工重置，直接在原地触发自主重试。
  - *轻量本地残差学习（$u_t$）*：将每次尝试的“指令修正 $u_t$ → 实际物理结果”存为在线试错数据，利用 **Online Model-Based RL** 拟合当前实体机器人与环境的局部残差动力学，动态规划下一次尝试的最优修正量 $u_t$，在不触碰任何冻结模型权重的前提下迅速收敛。

## 实验结果

真机人形机器人全自主评测（零人工遥操作、零任务专属仿真预训练，覆盖上下楼梯拾物、崎岖地形捡纸团/垃圾、靠近沙发、开柜门、搬箱与分拣入篮等长程全身任务）：

| 评测实验 | 方法 / 阶段 | 成功率（成功 / 总次数） | 机制归因解读 |
| --- | --- | ---: | --- |
| **真机垃圾拾取在线自演化** | ATLAS（连续 38 次自主尝试，无遥操作） | 滑动窗口 **0% → 88%**（末 8 次） | 直观展示 Harness 在单次真实部署会话中“从零抓空到稳定命中”的在线自愈能力 |
| **物体抬举四范式对照** | **Online Model-Based RL（ATLAS 学习动力学）** | **83%**（59 / 71） | **核心胜因**：局部残差动力学模型让几十次真机尝试即可精准反推非线性修正量 $u_t$ |
| 同上对照 | Bias Estimation（递推最小二乘 RLS） | 58%（66 / 114） | 只能补偿常值/线性静态偏移，面对随站姿、目标高度变化的非线性误差触顶 |
| 同上对照 | Model-Free RL | 13%（9 / 71） | 无模型试错样本效率太低，在几十次真机预算内几乎无法完成信用分配 |
| 同上对照 | No Learner（无在线学习基线） | 4%（16 / 378） | **最震撼的基线数据**：仅靠 VLM + 人类视频重定向 + 冻结全身跟踪器，物理断层会导致 96% 失败 |

## 总结讨论

### 核心 Takeaway 与可迁移启示

1. **那组 `4% → 13% → 58% → 83%` 的阶梯对照，是近年具身控制最清醒的一堂课**：
   - `No Learner (4%)` 证明：**单靠更好的 VLM 或更好的冻结全身控制器，根本跨不过真机最后一厘米的物理断层**；
   - `MFRL (13%)` vs `RLS (58%)` vs `Online MBRL (83%)` 证明：**在真机在线适应的极低样本预算（几十次尝试）下，显式建模低维残差动力学比盲目无模型探索有效 6 倍以上，且比简单线性偏置校准高出 25 个百分点**。
2. **给做 VLA / WAM / 人形控制的团队：把“策略训练”和“测试时 Harness 适应”拆开做**。不要指望靠堆更多离线遥操作数据把每台机器人的标定偏差、地面摩擦和相机抖动全部泛化掉；把冻结基础模型嵌进一个带“视觉成败检测 + 原地安全重试 + 低维 Online MBRL 修正器”的 Agentic Harness 里，性价比远高于全量重训。
3. **与本知识库其他路线的衔接**：ATLAS 的 Harness 当前依赖头部 RGB-D + SAM 做成败与位置反馈；若进一步接入 **π⁴** 这类免标定度量 4D 感知前端，甚至有望彻底摆脱对深度相机的硬件依赖，形成“纯 RGB 4D 验证 + 在线残差学习”的通用具身闭环。

### 批判性审视与适用边界

ATLAS 的高光建立在两个隐含前提之上：**（1）任务允许失败且能低成本原地重试**（如捡纸团、开柜门、搬箱）；**（2）成败与位置误差能被机载视觉清晰观测到**。一旦遇到打翻水杯、折断易碎品、不可逆跌倒或严重视觉遮挡的精细力控任务，测试时试错学习就会撞上安全与可观测性天花板。

## 局限、失败案例与开放问题

- **强依赖“失败可逆 + 可原地重试”**：在线基于模型 RL 需数十次真实尝试收敛，适合低风险拾取、搬运、开关操作，难以直接套用到不可逆破坏或高危失衡任务。
- **受限于前端视觉可观测性与成功判定**：头部 RGB-D + SAM 在强遮挡、透明/反光物体或接触力主导的装配场景下容易给出错误残差信号，进而污染在线动力学模型。
- **外围修正 $u_t$ 无法凭空创造底层新技能**：Harness 只调整高层目标与低维修正量，若人类示范包含冻结 System 0 根本跟踪不住的极限动力学动作，仍需升级底层控制器。
- **跨会话长期记忆（RSI）尚未闭环**：当前残差动力学主要在单次部署会话内快速生效，如何把跨任务学到的本体动力学误差持久化回写为长期先验，仍是通往递归自改进的关键一步。
