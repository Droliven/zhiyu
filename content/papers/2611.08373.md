## 当前挑战

二维图文预训练带来的视觉特征未必包含精细操作所需的三维结构；只在少量下游数据上补空间监督，又容易把空间能力限制在特定任务。跨本体数据的深度、标定与动作格式不一致，也阻碍统一训练。

## 研究动机

**SLA 把三维教师监督从下游适配前移到持续预训练，并在后训练保留，使空间理解成为策略可迁移的表征能力。** 它延伸 Spatial Forcing 路线，让已有 VLA 从更广的机器人经验学习几何知识，而不要求部署时运行三维教师。这里持续预训练指继续训练已有策略，未证明在线终身学习或学习算法自我改进。

## 技术方案

**输入**：策略使用图像、任务语言与本体状态；训练教师另外使用可用的深度、相机内外参。异构机器人数据统一末端位姿和坐标约定后参与训练。

**过程**：初始化 π₀.₅，同时优化动作预测与空间特征对齐；冻结的 OmniVGGT 提供几何特征，多层 VLA 视觉 token 经特征依赖门控融合、投影后与对应位置教师特征做余弦对齐。随机丢弃整段状态 token，减少轨迹记忆捷径；持续预训练与后训练均保留对齐目标。

**输出**：连续机器人动作。三维教师、投影器和门控仅用于训练；RoboDojo 的独立历史图像 memory 配置则在推理时保留，须与空间辅助分支区别。

对齐发生在 VLA 中间视觉特征与三维教师特征之间，并非直接把动作表示与三维表示对齐；三维信息通过用于动作生成的视觉 token 进入策略。[方法第 3 节](https://arxiv.org/html/2611.08373v1#S3)。

## 实验结果

| 评测 | 成功率 | 关键设置 |
| --- | --- | --- |
| LIBERO-Plus | SLA 87.4%，π₀.₅ 84.4% | 标准 LIBERO 训练；七类扰动，共 10,030 次 rollout，按 episode 数加权 |
| RoboTwin Clean2Random | 72.3%，π₀.₅ 46.0% | 50 任务，每任务 50 条 clean 示范，每任务每设置 100 次评估 |
| RoboCasa-Panda | 68.4% | 24 任务，每任务 50 条下游示范；3 seeds×每任务 50 次 |
| RoboDojo-Real | 33.9%，π₀.₅ 12.8% | 三本体、18 任务；另加入并部署历史图像 memory，不能无条件归因于训练期空间对齐 |

最直接的机制证据来自同数据的两阶段消融：RoboTwin C2R 两阶段均无对齐为 48.2%，仅后训练 57.1%，仅持续预训练 63.2%，两阶段均对齐 72.3%。这支持预训练和适配同时施加空间监督；状态 dropout、门控及旋转表示也改变结果，整套收益不能全归因于教师特征。

源数据表的 171.39 万 episodes、14,330 小时是筛选前统计，不是最终实际训练规模。自建真机八条件平均 83.8%，比 π₀.₅ 高 24.0 点；每条件按 50 个对象实例计，部分 rollout 含多个对象，不能称 400 个独立完整回合。[实验第 4 节](https://arxiv.org/html/2611.08373v1#S4)。

## 总结讨论

关键启发是将几何监督放进基础策略的规模化训练，而非把三维传感器简单叠在推理输入上。它验证的是三维教师指导下的视觉表征与控制泛化，尚未学习动作条件的未来世界演化；与 UniWAM、PrimeSim 应按这一接口边界比较。

## 局限、失败案例与开放问题

- 更强控制来自多项训练设计，三维对齐的独立收益需结合消融而非只看主榜单。
- RoboDojo 额外 memory 在推理时保留，“部署无新增空间模块”不能扩大成所有实验配置完全无额外输入。
- 原始数据规模与最终保留规模不同，教师利用的深度和标定也不在所有来源中可用。
- 视觉特征更接近三维教师不等于恢复了正确物理机制；未来动力学、因果识别及终身适应未由当前实验建立。
