## 当前挑战

2D 图文预训练出身的 VLA 主干天然缺 3D 几何感——作者的深度线性探针（Fig. 2）显示，纯 2D VLA 的视觉 Token 几乎恢复不出有效场景深度。现有两条补 3D 的路线各有硬伤：

- **推理期外挂 3D 传感器/点云**：会改坏原有 2D VLA 架构、难以复用预训练权重；且真机深度有噪声、大量公开机器人数据集压根没有深度或相机标定，规模化受阻。
- **只在下游后训练加隐式 3D 对齐**（如前作 Spatial Forcing）：把空间能力做成了“任务特化补丁”，换个场景、桌面高度或机械臂本体就容易掉点。
- **异构大规模数据本身有工程陷阱**：跨本体关节空间不兼容、欧拉角直接相减会在 $\pm 2\pi$ 处产生极端离群值、策略还容易背诵本体状态轨迹而忽略视觉输入。

## 研究动机

**核心思路：把隐式 3D 空间对齐从“下游微调补丁”前移到“大规模持续预训练”，并在后训练保持，让 3D 理解长进 VLA 底座权重里，而部署时零新增模块。**

既然动作解码直接读取 VLM 的中间视觉 Token，只要在训练期用冻结 3D 教师牵引这些视觉 Token，就能在不改 $\pi_{0.5}$ 主干与动作头的前提下内化 3D 几何。真正把这条路在百万级异构语料上跑通的，是配套的四件套：**兼容残缺标注的 3D 教师 + 自动选层的门控融合 + 逼策略看图的状态 Dropout + 跨本体统一动作几何**。

注：本文“持续预训练”指基于 $\pi_{0.5}$ 权重继续做大规模预训练，并非在线终身学习。

## 技术方案

**输入**：策略端接收多视角 RGB、语言指令与统一坐标系下的末端位姿；训练期外部 3D 教师额外吸收数据集中部分可用的深度与相机内外参。

**过程**：从 $\pi_{0.5}$ 初始化，在持续预训练与下游后训练两阶段联合优化动作损失与视觉—3D 教师余弦对齐损失；通过多层门控融合、25% 状态 Dropout 与 $\mathrm{SO}(3)$ 旋转向量统一异构数据。

**输出**：连续末端增量与夹爪动作块；3D 教师、投影器与门控在推理期全部丢弃（注：RoboDojo-Real 评测额外保留了推理期历史图像 Memory）。

核心设计拆解（[方法：第 3 节](https://arxiv.org/html/2611.08373v1#S3)）：

- **能“吃杂粮”的冻结 3D 教师（OmniVGGT）**：开源机器人数据有的带深度和标定，有的只有纯 RGB。OmniVGGT 通过 GeoAdapter 吸收可用几何标注、缺失时平滑回退到纯 RGB，使整套异构语料都能产出统一的空间监督目标。
- **特征依赖的多层自适应门控**：不同场景和本体适合对齐的 VLM 深度不同，手动挑单层既费事又脆弱。SLA 给全部 18 层 VLM 视觉 Token 配了共享的 token/通道级 Sigmoid 门控，按输入特征动态加权融合多层表示后再对齐教师，无需人工选层。
- **25% 状态 Dropout 破除轨迹记忆捷径**：机器人本体状态很精准，策略容易偷懒“看状态背轨迹”而不看图。训练时以 25% 概率整段丢弃状态 Token，迫使动作头真正利用对齐后的视觉空间特征。
- **跨本体几何统一与去冗余**：把所有机器人的末端位姿转到统一基座坐标系（前 $+x$ / 左 $+y$ / 上 $+z$），并用 $\mathrm{SO}(3)$ 相对旋转向量代替欧拉角相减（消除 $\pm 2\pi$ 跳变）；同时滤除异常速度/静止帧，并对高度重复的仿真子集按任务降采样。

## 实验结果

| 评测基准 | SLA 表现 | 核心对比与设置 |
| --- | --- | --- |
| **RoboTwin 2.0**（50 任务×50 clean 示范） | Clean2Random **72.3%** / 均值 **79.2%** | C2R 超越 $\pi_{0.5}$（46.0%，**+26.3 pp**）与 Spatial Forcing（62.6%，+9.7 pp），泛化提升最显著 |
| **LIBERO-Plus**（7 类扰动，10,030 rollouts） | **87.4%** | 超越 $\pi_{0.5}$（84.4%）与 Spatial Forcing（85.1%），7 维扰动全面提升 |
| **RoboCasa-Panda**（24 任务，仅 50 示范/任务） | **68.4%** | 超过同为 50 示范的 Cosmos Policy（67.1%），也超过 300–3,000 示范的 $\pi_0$（62.5%）、GR00T-N1.5（64.1%） |
| **RoboDojo-Real**（3 本体 18 任务单模型） | Score **42.3** / SR **33.9%** | 超越 $\pi_{0.5}$（12.8%）与 InternW0-$\Delta$（31.7%）；注：该配置在推理期额外接入历史图像 Memory |
| **自建真机 8 条件**（Piper 双臂 + Franka 单臂） | 平均 **83.8%**（全 8 项第一） | 较 $\pi_{0.5}$（59.8%）**+24.0 pp**、较 Spatial Forcing（68.0%）+15.8 pp；动态目标移动（76% vs 42%）与 10 示范跨本体迁移（78% vs 48%）优势突出 |

**最能说明机制的两组消融（RoboTwin）**：
- **数据扩展 × 两阶段对齐（Table 6，C2R）**：无对齐时数据从 5% 扩到 100% 几乎原地踏步（43.8% → 48.2%）；仅后训练对齐为 57.1%，仅持续预训练对齐为 63.2%，**两阶段都对齐则一路涨到 72.3%（+23.1 pp）**——说明 3D 对齐显著打开了数据扩展的天花板。
- **其他关键因子的独立贡献（Table 7–10）**：25% 状态 Dropout 把均值从 38.1% 拉到 79.2%（**+41.1 pp**）；多层自适应门控比最佳固定层第 12 层高 +5.0 pp（C2R）；$\mathrm{SO}(3)$ 旋转向量（79.2%）明显优于欧拉角（65.5%）与 Rot6D（62.9%）；给教师补入相机标定再增 +3.2 pp。[实验：第 4 节](https://arxiv.org/html/2611.08373v1#S4)。

## 总结讨论

SLA 证明了一条很务实的工程与研究路径：**单纯堆 2D 异构动作数据很容易撞墙，而把 3D 几何监督放进基础策略的持续预训练，能让数据规模真正转化为跨视角、跨高度、跨本体的空间泛化力，同时守住原 2D VLA 的零开销推理接口。**

但阅读时必须守住归因边界：主榜单的巨大跃升是**“两阶段空间对齐 + 25% 状态 Dropout + 旋转向量统一 + 自适应门控”**协同的结果（尤其状态 Dropout 单项影响极大），不能全记在 3D 教师头上。此外，SLA 强化的是“当前帧视觉表征的 3D 几何感”，尚未建模动作条件的未来世界演化与接触动力学。

## 局限、失败案例与开放问题

- **多因素耦合归因**：状态 Dropout、旋转向量和多层门控本身带来巨大收益，评估 3D 对齐的净贡献必须看同配置消融表（Table 6）。
- **“推理零新增模块”存在例外**：RoboDojo-Real 评测在推理期保留了历史图像 Memory，不能把所有榜单结果一概归为纯原版架构推理。
- **筛选后数据规模与标注不均**：实际保留训练量远低于源数据总量，且深度/标定仅部分数据可用；当前亦排除了灵巧手与移动底盘。
- **表征对齐 ≠ 世界动力学**：视觉特征贴近 3D 教师提升了几何鲁棒性，但策略仍不具备未来后果预测、物理接触推理或失败恢复能力。
