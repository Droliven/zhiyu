## 汇报架构（18 页）

- **封面与目录（P01–P02）**：明确总—分汇报脉络与五大核心板块。
- **第一部分 · 总体背景与规划框架（P03–P05）**：
  - P03：宏观背景——4D 交互世界表征作为具身智能的“空间中间语言”（承接“3D as Code”逻辑）。
  - P04：五大方向动因——从 4D 几何运动学走向真实物理交互的四堵结构性高墙。
  - P05：总体规划框架（上 → 中 → 下，全原生可编辑）：上层 4D 数据飞轮与诊断评测 → 中核 4D 几何到物理因果 → 共享最小 4D 状态接口 → 下层三条正交能力跃迁 + 右侧自下而上闭环回流。
- **第二部分 · 五大核心板块深挖（P06–P15，每板块 2 页：进展/代表工作/局限 + 可研课题/验证设计）**：
  - 板块一（P06–P07）：4D 几何增强 → 免标定、跨遮挡持久的原生 4D 场景 Token（含 `GAF / GAF-WAM / Gnomon4D / π⁴` 原图）。
  - 板块二（P08–P09）：物理增强与因果世界建模（含 `PointWorld` 原图，VLM 先验 + 主动交互探测 + 动作条件因果动力学）。
  - 板块三（P10–P11）：动态操作与实时闭环（含 `X-WAM` 原图与 `DynamicWAM` 失败分布图，接触事件驱动自适应执行时域 + 异步 RTC）。
  - 板块四（P12–P13）：人类示教 ICL 高效迁移（含 `μ₀` 原图，联动组内 HOI 4D 重建抽取跨本体 4D 交互不变量）。
  - 板块五（P14–P15）：4D Agent / Harness 与自进化（含 `SpatialHarness` 原图，Verify in 4D 预测—实测残差驱动恢复与门禁进化）。
- **第三部分 · 横向协同、公共底座与推进路线（P16–P18）**：
  - P16：同一动态精密插接任务贯通五板块与解耦协作接口。
  - P17：4D 数据飞轮（三源互补、可靠度分层、失败驱动回流）、四层诊断评测尺与触觉/力觉延伸。
  - P18：三阶段科研推进路线与三组 2×2 交叉验证门槛。
