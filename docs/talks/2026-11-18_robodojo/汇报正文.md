# 具身操作策略与闭环智能体：RoboDojo 代表工作分析与 4D 研究方向

> 核心结论：端到端策略（VLA/WAM）提供低延迟连续控制基础，闭环 Agent 在开放指令理解与跨时段记忆上显著占优；在剔除开放任务的四项评测口径下，精细接触操作与随机布局泛化是拉开总体排名的主要因素。现有高分仿真 Agent 已广泛使用基于相机内外参的解析射线几何，但在真机免标定、接触自遮挡、未知高度与连续滑移判别上仍存在明显局限，为前馈 4D 跟踪表征与动作条件 4D 世界模型提供了明确的研究切入空间。

## 一、榜单表现与定量分析

RoboDojo-Sim 包含 42 项双臂操作任务，公开提交共 71 项：端到端策略模型 57 项（按泛化、精细、长程、记忆、开放五项等权均分排序），闭环与自进化 Agent 系统 14 项（官方按剔除开放任务后的四项等权均分排序）。

| 系统 | 类别 | 标准泛化 | 随机泛化 | 精细操作 | 长程执行 | 跨时记忆 | 开放指令 | 四项均分 | 五项均分 |

| Liber-0 Preview | VLM+WAM | 39.31 | 10.67 | 38.28 | 45.98 | 37.77 | 6.68 | 36.76 | 30.74 |
| GO-3 Nano Preview* | Agent+WAM | 45.93 | 26.97 | 78.65 | 68.21 | 64.50 | 61.71 | 61.95 | 61.90 |

主要定量结论：

1. **分维度规律（不做跨模型组平均）**：开放指令呈现明显阵营分界（全部 Agent ≥28.88，全部策略 ≤20.76）；但精细操作与随机布局泛化取决于具体系统设计而非是否引入 Agent——剔除开放任务后，WALL-OSS（48.05）与 VPP2（47.93）的四项均分高于 WorldScape-R²SI（45.93）和 PhysicalRSI（38.12）。
2. **同基座受控对比与单轨拉动效应**：固定同一基座模型 GPT-6 Astra 时，引入 R²SI 或 RoboRSI 可将长程执行提升 30 至 45 分、跨时记忆提升约 23 分。在策略榜中，引入历史帧记忆可将总分提高约 10 分，保留 VLM 语义先验使 WALL-OSS 在开放轨道领先 VPP2 16.15 分（折合五项总分 +3.23 分）；在剔除开放任务的 Agent 榜中，记忆与长程差距收敛，精细操作（GO-3 领先 SenseNova 38.49 分，折合四项总分 +9.62 分）与随机布局泛化直接决定头部名次。
3. **影响操作性能的三类关键因素**：受控实验一致表明，精确动作测量标注（Liber-0 中 1 万小时传感器手套数据优于 200 万小时无标注网络视频）、高层子目标分解与闭环动作审查（商汤报告中开环调 VLA 仅 5.83%，4 步闭环审查升至 25.83%，结合经验包达 54.17%）、接触区域的空间可观测性（SpatialHarness 在冻结策略下将四项真机精细任务平均成功率提升 65.0 个百分点），比单纯增加模型参数量或原始视频时长更具解释力。

## 二、七项代表工作要点

- **WALL-OSS-1.0-lite（自变量机器人）**：基于 Qwen3.5-4B，采用离散动作、图文任务与连续流匹配协同预训练保留 VLM 语义能力；推理时通过滑窗关键帧筛选维持记忆（57.42 分），并用 4 轮链式残差模块精化 32 步双臂末端轨迹。
- **VPP2（RobotEra 与清华大学）**：在 1–12s 完整子任务视频上做事件级续训后，经一致性蒸馏将 8s 视频潜特征预测压缩为单步前向（0.12s），再冻结视频主干（仅开 LoRA）训练 0.9B Action DiT 读取视频 KV 缓存生成动作（总延迟 0.22s），ALOHA 真机零样本达 58.5%。
- **Liber-0 Preview（LiberAI）**：结合穿戴式 LiberSense 手套动作锚点、语言/视觉/动作三专家 MoT 联合架构（含统一本体运动学编码）与拟人机器人 LEO 对齐人机观测。RoboDojo 提交代码中由上层 Qwen3-VL 先输出子任务与目标框，再交由底层 WAM 生成 32 步关节动作。
- **GO-3 Nano Preview（智元机器人）**：区分官网旗舰发布（WRAM 架构与百机混合后训练）与 RoboDojo 实际开源实现（`go3_agent_preview`）。评测时每局先运行 Python 生成器任务程序，仅当程序局部恢复耗尽并显式触发 `switch_to_wam` 时，才通过 WebSocket 单向交由独立 GPU 上的 GE-Act WAM 持续控制至回合结束。
- **SenseNova-RoboRSI（商汤科技）**：离线从训练集示范总结只读任务经验包；在线由底层 OpenPI `π0.5` 容器提议短步末端动作，上层 VLM 每隔 4 步做闭环审查修正。第二阶段将环境验证通过的交互轨迹转化为监督样本微调开源 `RoboRSI-27B-Preview`，在 RoboCasa365 上成功率由 26.0% 升至 46.5%，平均输出 Token 减少 73.3%。
- **WorldScape-R²SI（Manifold AI）**：内层 Robot Agent 每步在控制工具与反应模型 WSP（执行单个短动作块后立即归还控制权）之间选择；外层 Recursion Agent 分析探索记录，同时更新通用 `SKILL.md` 与反应模型权重，经多布局步数预算门禁验证达标后自动晋升。
- **PhysicalRSI 1.0（港大 MMLab 与 Kinetix AI）**：在线评测时由 VLM 看首帧从预置技能库（22 个 Python 控制程序与 `π0.5`）选定一套程序执行；离线开发时根据失败录像并行改写多版 Python 控制代码（定位、状态字典、中转位姿、阶段公差），通过实测跑分筛选保留最高分版本。

## 三、核心机制对比

### 1. VLA / VLM 与 WAM 的三种分工方式

1. **上下层串行引导**（`Liber-0 Preview`、`VPP2 + VLM`）：上层 VLM 输出有序子任务与目标二维框，底层 WAM 据此预测未来视觉特征与短程关节动作块。
2. **候选提议与价值评估**（`LAW`、`ME-Brain-1.0`）：WAM 在训练期提供动态监督并在推理期输出候选动作（部署期可省略像素视频生成），由上层 VLM 异步评估进度并通过 Value 模块对候选动作评分融合。
3. **按操作阶段切换**（`Veo-Act`、`DualWAM`）：大范围自由空间移动由视频世界模型规划轨迹，末端接近目标进入接触阶段时切换给高频闭环 VLA 执行。

### 2. Agent / Harness / RSI 的层次区别与四系统局内/跨局对比

- **三层实质区别**：单局在线 Agent 仅解决当次重试，不跨局保留经验；Harness 重构模型外围的观测加工、显式状态存储与控制原语接口；RSI 通过独立的外层复盘修改代码/技能文档（`ΔH`）或模型权重（`Δθ`），并依靠固定测试集回归门禁拦截退化版本。
- **局内与跨局一致对照**：`WorldScape-R²SI`（单 chunk 交回）与 `SenseNova-RoboRSI`（每 4 步审查）局内保持高频在线监督，并在跨局将验证轨迹回流更新模型权重（前者微调反应模型，后者微调 27B VLM 减少 73% Token）；`GO-3 Nano`（代码主控 + 异常单向切 WAM）与 `PhysicalRSI`（开局选定状态机程序）局内由本地代码主导，跨局仅修改外部控制脚本。

## 四、3D/4D 结合现状与研究课题

### 1. 现有具身 Agentic 系统的 3D 利用现状（从榜单解析射线到静态三维表征）

围绕“用没用 3D、用的什么 3D、怎么用的 3D”做统一梳理：

- **（一）RoboDojo 榜单实战系统**：仿真协议虽不提供深度图，但开放了相机内外参标定与机械臂正运动学。`GPT-6 Astra 直控` 与 `WorldScape-R²SI` 未使用显式 3D（仅靠 2D RGB 推理），精细操作得分偏低（12.65 / 23.51）；而 `Q0-Preview`（精细 65.30）、`GO-3 Nano`（精细 78.65）与 `PhysicalRSI` 已在 Python 工具中使用**精确相机内外参 + 预设桌面高度平面 + 正运动学**，通过单目射线—高度平面求交、双视角手动选点三角化与微抬重投影校验计算三维位姿。该方案依赖理想外参与已知高度平面，且无法应对薄边缘误匹配与接触自遮挡。
- **（二）近期具身 Agentic / Harness / RSI 学术论文**：为突破手工射线局限，近期工作引入了三类静态/符号化三维信息——（1）**多视角重建 + 刚体/关节 CAD 模型**（`SpatialHarness` 在线同步三维仿真场景渲染互补虚拟视角，真机四任务 +65.0pp）；（2）**三维几何面角色与三维关键点**（`Geometric Abstraction`、`SPARK`、`ReKep` 将控制程序参数实时绑定到三维几何基元局部纠偏，但接触遮挡时标记为不可用）；（3）**物体局部系下的相对三维位姿规则**（`RoboHarn-Evo`、`MOTIO` 在跨回合 RSI 中修订相对几何动作规则库）。总体来看，现有具身 Agentic 系统停留在**静态、刚体、依赖标定或 CAD 先验的 3D**；而建模连续时间演化的动态 4D 模型（`Gnomon4D`、`PointWAM`、`PointWorld`）均尚未接入高层 Agent 的状态核验、失败归因与跨回合自进化。

### 2. 围绕 4D 表征与模型的三个高辨识度课题

1. **课题一（状态感知层）：免 CAD 的持久化 4D 场景记忆与“去夹爪透视”观测**。针对瞬时几何方法在夹爪遮挡目标瞬间丢失三维坐标、而 `SpatialHarness` 依赖预建刚体 CAD 资产的痛点：在接近前视线清晰阶段用前馈多视图重建锁定插槽与手持物末端的局部三维表面；进入接触遮挡期后，利用精确已知的机械臂 URDF 剔除夹爪遮挡像素，结合手腕运动与局部可见边缘在持久 4D 状态中持续追踪物-槽三维相对位姿，实时向冻结策略或 Agent 渲染去夹爪的正交透视截面并输出毫米级间隙偏差。
2. **课题二（控制与进化接口层）：以“4D 交互轨迹（Trace）”取代自然语言与死代码，连接 Agent 与底层策略**。针对自然语言子任务太粗糙、而 Python 关节控制脚本写死平面假设导致随机布局泛化差（11.04 分）的结构矛盾：由高层 Agent 规划并编辑稀疏 4D 关键轨迹规范（未来 1–2s 手与目标关键点的三维空间曲线及开合事件）；底层接以三维轨迹为条件的轻量策略（可直接在海量无机器人动作标签的人类操作视频上提取三维手-物轨迹预训练）。执行失败时将“规划 4D 轨迹”与“实测 4D 轨迹”在同一坐标系做差（`ΔTrace`），实现跨随机布局与跨机械臂本体的自进化复用。
3. **课题三（接触反馈层）：对比“指令预期运动”与“实测 4D 运动”，实现无力传感器的接触纠偏**。针对低成本双臂（如 ARX-X5、ALOHA）缺少六维力矩传感器、插接卡阻后单看静态图不知往哪侧调整的问题：对比控制器下发的已知预期运动（例如垂直下移 2.0 cm、旋转 0°）与腕部相机跟踪到的物体可见表面实测三维运动（例如仅下移 0.4 cm 即停滞，且发生向右 +3° 微小三维偏转）。由杠杆几何可直接反推出插头底部左侧磕在孔左沿，从而算出“向右平移 3 mm 再下压”的精确纠偏指令，并将修正量绑定到目标物体局部三维系供后续回合直接复用。
