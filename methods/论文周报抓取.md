## 一、课题有机逻辑梳理（为什么这些方向是一个整体）

原先罗列的具身智能与手物交互（HOI）子课题看似分散，实则围绕**同一个核心中间语言——“以接触与相对运动为核心的 4D 交互状态表征”**，构成「**上游人类交互感知/重建/生成 $\leftrightarrow$ 下游具身世界建模/控制/自进化**」的完整闭环：

```text

  A1. 语义与跨视角理解（黎峻佟 HOI 表示学习 / 邱梓彦 Ego-Exo 跨视角理解）
        ↓ 提供交互阶段切分、接触语义先验与跨视角不变表征

        │  • 反向约束：真机闭环成败、运动学可达性与预测—实测物理残差，反向检验重建与生成的物理可执行性
```

**补充补全的三个关键盲区**（对应 `plan.md` 中“可能还有其他的我没写全”）：
1. **力觉/触觉与 4D 接触场的耦合（Tactile / Force-Aware WAM & VLA）**：精密插拔、装配与铰接操作中，纯视觉在接触瞬间存在力与微滑移盲区，需纳入视觉—触觉/力矩—动作联合建模与测力物理辨识。
2. **持久 4D 空间记忆（Persistent 4D Spatial Memory）**：长时程操作与跨视角遮挡下，如何以低开销维护物体身份、状态与已探索几何，而非仅依赖当前局部窗口帧。
3. **生成式闭环仿真器与数据飞轮（Actionable World Simulators & 4D Data Engines）**：用动作条件世界模型直接充当策略评估器或模型内强化学习环境（如 PrimeSim 路线），与 Agentic 仿真资产生成共同闭环。

```text
# 二、核心研究图谱与检索雷达（双翼闭环框架）

围绕「以接触与相对运动为核心的 4D 交互状态表征」这一共同主轴，重点检索以下两大主线及连接桥梁的高质量工作：

## 主线 A：手物交互（HOI）——理解、3D/4D 重建与可控生成
- **A1. HOI 语义表征与 Ego-Exo 跨视角理解**
  - 交互动作阶段切分、细粒度接触状态与功能可供性（affordance）表示学习；
  - 第一视角与第三视角（Ego-Exo）跨视角对齐、视角不变交互表征、双手—多物体结构化关系建模。
- **A2. 从单图到流式视频的 3D/4D 手物与交互资产重建**
  - 单图或稀疏视角手物联合重建：结合图像重投影反馈与三维接触/防穿模几何反馈的前馈或循环自校正对齐（替代慢速脆弱的逐实例测试时优化）；
  - 第一视角流式世界坐标重建：解耦手部运动与相机自运动、利用人手尺度先验与 3D 场景基础模型双向标定消除单目尺度与深度畸变、长窗口无漂移流式跟踪；
  - 重度遮挡下的生成式手物恢复：利用几何基础模型跨视角投影与多视角视频扩散先验补全被遮挡手部关节与接触构型；
  - 交互物体的遮挡鲁棒与拓扑一致 4D 重建：耦合时序非模态形状补全与三维点追踪，恢复持久顶点身份（persistent vertex ID）、固定网格拓扑，解耦刚体位姿变化与局部非刚性/铰接形变，以及从视频/测力交互恢复可操作铰接物体资产。
- **A3. 2D–3D 共生、物理感知与 Agentic 交互生成**
  - 原生 3D 几何/轨迹与 2D 视频扩散/流匹配模型的逐步双向共生生成（如去噪中联合建模视频潜变量与显式 3D 手物网格/点轨迹、深度与遮挡重投影回注），实现 360° 几何一致与接触合理的 HOI 生成；
  - 物理感知生成与后训练优化：利用 VLM 物理合理性判别、接触/穿透约束、可微几何反馈或强化学习/偏好对齐（GRPO/DPO/RL）消除悬浮、穿模与物理违和伪影；
  - Agentic VLM 规划驱动的生成：由多智能体或 VLM 将高层语言意图分解为时序阶段、接触顺序与空间约束蓝图，驱动 2D–3D 手物生成及跨本体的具身机器人操作视频/轨迹生成。

## 主线 B：具身智能（Embodied AI）——4D 世界动作模型、物理实时控制与自进化 Agent
- **B1. 3D/4D 几何与运动增强的世界动作模型（WAM / VLA）**
  - 重点审视几何如何真正服务控制，明确区分三条路线：① 仅作训练期辅助监督/特征蒸馏（推理期丢弃）；② 预测 3D 点流/轨迹再交由独立控制器解码；③ 推理期显式或隐式保留动态几何并与动作紧耦合；
  - 动态 3D 高斯场（4DGS/Gaussian Action Field）、原生 3D/4D 场景基础模型（如 VGGT 系列、π³ / π⁴ 等免标定前馈几何主干）与视频动作模型的特征对齐、未来几何记忆条件化；
  - 交互显著性驱动的时空聚焦读取：如何利用末端/手—物体相对运动场（如 4D 图像平面与深度位移场）引导动作专家聚焦于**接触交互区域（Where）**与**抓取/释放切换关键帧（When）**，克服稠密注意力偏向机械臂本体的捷径学习。
- **B2. 物理增强、力触觉耦合与因果世界建模**
  - VLM 物理常识先验与在线主动交互参数辨识（质量、质心、摩擦、阻尼、铰接轴与负载特性）进入策略或世界模型；
  - 接触密集型操作中的视觉—触觉/力矩—语言—动作耦合（VTLA、精密插拔、装配、薄软与可变形物体操作）；
  - 可单独调用的动作条件 3D/4D 前向动力学模型与基于预测后果的规划优化；世界模型中的真实干预（intervention）、反事实审计与因果可识别性。
- **B3. 动态操作、流式预测与实时异步闭环**
  - 超越准静态桌面抓取的动态操作（运动目标拦截、高速推挡、抛接、接触冲击适应、流体与柔性体动态控制，如 DynamicWAM 方向）；
  - WAM 推理效率与闭环控制机制：快慢共享或异步去噪时钟、跳过冗余像素精炼的动作早出机制、流式/滚动想象（Streaming / Rolling WAM）、实时动作分块平滑衔接（RTC）与接触事件触发的自适应重规划时域。
- **B4. 人类示教高效迁移与具身上下文学习（连接 A 与 B 的核心桥梁）**
  - 大规模无动作标签人类第一视角视频的跨本体预训练：重点关注无需脆弱关节重定向（retargeting）的共享中间接口（4D 表面运动场、3D 交互迹、4D 可供性、世界转移潜动作）及按标签可靠度分级监督策略；
  - 具身上下文学习（Embodied In-Context Learning / Test-Time Adaptation）：部署期无需更新权重，通过少量人类视频示范、机器人示范或交互历史在线提取任务结构与空间对应，快速泛化至新物体与新场景。
- **B5. 具身 Agent、3D/4D 空间 Harness 与自进化闭环（RSI）**
  - 摒弃“仅靠提示词拼装观察—规划—执行循环”的表层工作，重点追踪三类实质机制：
    1. **3D/4D 空间 Harness**：通过显式三维场景重构、多视角重投影、几何抽象重绑定或持久 4D 状态追踪，补齐冻结 VLM/策略的精细空间度量与跨遮挡记忆（如 SpatialHarness 路线）；
    2. **规划—控制与验证恢复契约**：可执行控制程序生成、分层子任务调度、WAM 动作候选 + 价值/世界预测选优，以及基于 4D 预测—实测残差的自主失败检测与在线恢复；
    3. **递归自我改进（RSI）**：跨回合经验证技能/经验库沉淀、Agent 驱动的可交互物理仿真资产合成（Sim-Ready World Generation）以及闭环数据回流驱动策略/世界模型持续进化。

## 公共底座 C：4D 具身数据引擎、可交互生成仿真器与诊断基准
- 高精度多视角/第一视角 4D 操作数据采集与自动标注管线；
- 动作条件生成式世界模型作为闭环策略评测器或模型内强化学习仿真器（核查其与真实物理/真机策略排序的一致性及防奖励黑客机制）；
- 具身操作与 4D HOI 的高区分度新基准（重点关注精细操作、动态交互、空间记忆、开放指令与视觉/物理 OOD 泛化的定量归因）。

1. 在表征接口、跨模态耦合机制、控制/规划契约、跨本体训练范式或可扩展数据合成管线上给出清晰原创洞察，并由严格受控消融支撑；

3. 与上述 A1–A3、B1–B5 任一子方向直接相关，尤其是可能直接影响团队在研课题新颖性（novelty）的近邻竞争工作。

**主动排除或降级标准**：
1. 仅将现成模块简单拼接、更换骨干调参且缺乏机制消融的增量水文；
2. 标题含“World Model / 4D / Embodied / Agent”，但实质为纯自动驾驶感知、纯室内导航、无手物接触的全身人体动画或无动作/几何约束的通用文生视频，且对上述主线无明确可迁移机制的工作（归入排除统计并简述原因）；
3. 仅有社交媒体宣传、商业博客或二手解读而无原始论文（arXiv / OpenReview / 正式会议期刊页 / 详实官方技术报告）的线索，一律不得进入正式编号卡片，只能放入“待人工核验线索”。

# 四、事实核验与学术品味（Taste）准则

## 1. 原始来源核验与证据分级
二手聚合站（Hugging Face Papers、papers.cool、社区贴文等）仅作发现线索。正式卡片的所有关键事实必须回溯核对：
1. 原论文正文（优先读取 arXiv HTML 或 PDF 全文的方法、实验、消融与局限章节）；
2. OpenReview 或正式会议/期刊出版页；
3. 官方项目页、GitHub 代码仓、Hugging Face 数据/权重页。

若因网络受限无法读取正文、仅能核验摘要时，必须在卡片元数据标明 `仅核验摘要`，并在正文中如实限定陈述范围，严禁凭标题或摘要脑补网络结构、损失函数、实验数值、开源状态或失败案例。

## 2. 写作与审稿品味（核心要求）
每张论文卡片必须写成一份**逻辑清晰、判断独立、说人话的严肃学术精读备忘录**：
- **拒绝公关腔与玄学造词**：严禁使用“颠覆性突破”“范式革命”“赋能具身生态”“构建闭环护城河”等商业宣传语；遇到原论文自造的晦涩包装词（如把简单加权池化或常规重投影包装成复杂术语），必须用平实精准的数学/工程语言拆穿其真实操作。
- **锚定最近邻做增量剖析**：不孤立复述方法流程，必须点明它相对最近邻基线**究竟改变了哪一个假设、哪一层接口或哪一种监督信号**。
- **严格区分四层口径**：① 作者明确主张；② 受控实验直接证明的结论；③ 审阅者基于证据链的独立推论；④ 尚未验证的外推假设。
- **审计实验公平性与口径陷阱**：
  - 区分系统级对比（不同预训练数据量、不同骨干参数量、额外特权输入如真值深度/掩码/相机外参）与受控单因素消融；
  - 区分开环离线指标（MSE、重投影 IoU、仅在检出帧计算的 PA-MPJPE）与闭环真实指标（含漏检惩罚的 presence-aware 误差、世界坐标米制误差、真机/仿真闭环成功率）；
  - 区分模型单次前向耗时与完整规划/优化闭环周期（例如多轮采样优化耗时数秒不可表述为实时闭环控制）；
  - 涉及因果建模时，严格区分动作条件预测（action-conditioned prediction）、时序因果掩码（temporal causal attention）、干预重放归因（interventional rollout）、结构因果模型（SCM）与可识别反事实推理（counterfactual identification），严禁把相关性或条件生成夸大为因果性。
```
